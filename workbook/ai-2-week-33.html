Practice 1: explain the deciding evidence

Which labelled step matches this detail? Reordering the input rows must not change D’s unique winning score.

1. Choose best

2. Filter

3. Deterministic output

Hint if needed: Read the steps in the pictorial case. Match the supplied detail to the stage that performs or records it.

After your attempt, compare with the supported explanation: Deterministic output Reordering the input rows must not change D’s unique winning score. Eligibility and ranking answer different questions. C has a high preference score but is not an animal book, so it must stay excluded. The implementation needs a no-match result and explicit tie policy even when this example has a unique winner. Save rejected reasons for an explanation, not just the final ID.

Practice 2: explain the deciding evidence

Changed-case practice: Change D’s pages to 91, leaving every other field unchanged. Which conclusion is supported by the supplied facts?

1. D becomes ineligible, so A wins with score 2.

2. This one example guarantees correct results for every future input.

3. We can decide the result without examining the changed input or the procedure.

Hint if needed: Use the changed condition and the deciding step in the pictorial trace. The answer must say what follows from those facts.

After your attempt, compare with the supported explanation: D becomes ineligible, so A wins with score 2. The strict excess over the 90-page maximum changes filtering before ranking.
