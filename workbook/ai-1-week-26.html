01. Prompts Are Design Instructions: the case

A fictional club needs a short exhibit card, without guesses. Supplied facts: Source A: exhibit Paper Birds, location Shelf 2. No duration appears.

Required output: two labelled lines, Exhibit and Duration; missing values must say not supplied.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

State task: Produce exactly two labelled lines using source A only. → Find evidence: A supplies Paper Birds but no duration. → Follow missing rule: Exhibit: Paper Birds.

Duration: not supplied. → Check contract: Check labels, two-line format and each factual claim.

Point to each numbered stage and explain which recorded input it uses.

03. From prompt requirement to evidence of success

From prompt requirement to evidence of success. Use source C only | Monday and Room 7 | Compare with C. Mark missing values | Time: not stated | Check absent time.

Four labelled lines | Day Time Place Bring | Count and inspect. No added details | No invented promises | Check every claim

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Check labels, two-line format and each factual claim. Changed condition: Update the prompt to authorise sources A and B. Add B naming the same exhibit duration 20 minutes, with B declared current and authoritative.

Expected result: Duration becomes 20 minutes. Reason: There is now an authorised source for the previously missing field.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

A useful prompt describes both the wanted answer and what to do when evidence is insufficient. Asking for a duration does not create one. Examples can demonstrate the format, but they must not become sources of event facts.

Check content support separately from whether the answer looks tidy. Limit: Even a complete prompt does not guarantee an AI system follows it; test returned outputs against the contract.

Explain the case, then point to a limit on the claim.
