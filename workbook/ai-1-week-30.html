A fictional classroom chooses a storage bin for model parts. Supplied facts: Catalogue order: B1 capacity 5, B2 capacity 9. Valid request is a whole part count 1–12.

Return first bin with capacity at least the count; none if neither fits; clarify invalid input.

02. Follow the deciding steps

Validate request: Count 6 is whole and within 1–12. → Check first bin: B1 capacity 5 is below 6; reject it. → Check second bin: B2 capacity 9 is at least 6; accept it. → Baseline output: Report B2 and stop; save the comparison evidence.

Point to each numbered stage and explain which recorded input it uses.

03. The manual checklist baseline

The manual checklist baseline. Validate the request | Check minutes and Yes or No | Clarify invalid input. Inspect catalogue in order | Check time and quiet for each | Mark compatible rows.

Choose or explain absence | First compatible row or none | Suggestion or no match. Keep the evidence | Record input, result, reason | Comparable baseline record

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Report B2 and stop; save the comparison evidence. Changed condition: Change request 6 to 5. Expected result: The baseline returns B1. Reason: Its capacity equals the request, and at least includes equality.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.
