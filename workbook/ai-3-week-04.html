01. Sampling and Variability: the case

A fictional two-token distribution illustrates variability in generation. Supplied facts: At T=1, A=0.8 and B=0.2. For positive T use p^(1/T), then normalise.

Use token order A,B and cumulative intervals [0,boundary),[boundary,1). Draw u=0.85.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Original distribution: A boundary 0.8; u=0.85 selects B. → T=0.5 weights: Square probabilities:0.64 and 0.04; total 0.68. → Normalise: A=16/17≈0.9412; B=1/17≈0.0588. → Same draw: 0.85 is below 16/17, so T=0.5 selects A.

Point to each numbered stage and explain which recorded input it uses.

03. Temperature-scaled toy probabilities

Temperature-scaled toy probabilities. A: T=1 = 0.8, T=0.5 = 0.9411764705882353. B: T=1 = 0.2, T=0.5 = 0.058823529411764705.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: 0.85 is below 16/17, so T=0.5 selects A. Changed condition: Set the draw to 0.97, keeping both distributions. Expected result: Both temperatures select B.

Reason: 0.97 exceeds both A boundaries, 0.8 and approximately 0.9412.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Lower positive temperature concentrates this unequal distribution on its larger entry. It changes sampling probabilities, not evidence for whether A or B is true.

Using the same draw isolates how the distribution changes the decision. This formula is a toy probability-space illustration corresponding to a temperature-scaled model distribution.

Limit: Two tokens and one draw do not predict every output; temperature alone does not solve hallucinations.

Explain the case, then point to a limit on the claim.
