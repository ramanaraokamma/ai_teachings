Use this supported practice once, in the browser or on paper. Keep the reserved independent assessment for a separate first attempt before teacher feedback.

A fictional badge reader will be used in both bright and dim rooms.

Practice 1: explain the deciding evidence

Which labelled step matches this detail? Select and record new cases from both dim groups before claiming coverage.

1. Target conditions

2. Current sample

3. Targeted follow-up

4. Coverage gap

Hint if needed: Read the steps in the pictorial case. Match the supplied detail to the stage that performs or records it.

After your attempt, compare with the supported explanation: Targeted follow-up Select and record new cases from both dim groups before claiming coverage. Adding more bright cards can increase sample size without addressing the missing condition. A coverage check asks which relevant situations are absent, not merely how many rows exist. Deliberately selecting dim cases helps investigate those conditions, but the resulting test should not be advertised as a random survey unless its selection really was random.

Practice 2: explain the deciding evidence

Changed-case practice: Add eight more bright plain cards and no dim cards. Which conclusion is supported by the supplied facts?

1. This one example guarantees correct results for every future input.

2. We can decide the result without examining the changed input or the procedure.

3. The sample becomes larger but still has no dim coverage.

Hint if needed: Use the changed condition and the deciding step in the pictorial trace. The answer must say what follows from those facts.

After your attempt, compare with the supported explanation: The sample becomes larger but still has no dim coverage. The missing lighting condition remains untested.
