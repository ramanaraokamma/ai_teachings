01. Dataset and benchmark limitations: the case

A benchmark can miss the intended setting. A plant model is evaluated on clean indoor photos but proposed for shaded outdoor photos. Supplied facts: Indoor benchmark: 9/10 correct. No outdoor cases are present.

The same model is intended for both.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Name measured setting: All ten benchmark images are clean indoor photos. → Report the result: The observed indoor score is 90%. → Name missing evidence: Outdoor shade performance remains unmeasured.

Point to each numbered stage and explain which recorded input it uses.

03. Benchmark conditions

Benchmark conditions. Indoor benchmark: Correct = 9, Total = 10. Added outdoor slice: Correct = 2, Total = 4.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Outdoor shade performance remains unmeasured. Changed condition: Add four reserved outdoor cases, of which two are correct. Expected result: Report the outdoor slice as 2/4=50%, separately from indoor results.

Reason: The new records finally measure the missing condition, with a small denominator.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

A benchmark represents particular tasks and collection conditions. High performance on it cannot automatically establish fitness for a different deployment setting.

Limit: Neither slice estimates all future photos; inspect sampling, labels and grouping.

Explain the case, then point to a limit on the claim.
