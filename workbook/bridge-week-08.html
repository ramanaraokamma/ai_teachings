01. Functions and arguments: the case

Match arguments to parameters. A function prints the difference between capacity and reserved spaces. Supplied facts: Python 3: def show_free(capacity,reserved): print(capacity-reserved).

Calls: show_free(11,3); show_free(3,11).

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Define without calling: The definition creates the function but prints nothing yet. → Match first arguments: capacity=11 and reserved=3 give a printed 8. → Trace reversed call: capacity=3 and reserved=11 give -8 under the same arithmetic.

Point to each numbered stage and explain which recorded input it uses.

03. Arguments matched in order

Arguments matched in order. show_remaining(12, 4) | capacity 12; used 4 | 8. show_remaining(10, 7) | capacity 10; used 7 | 3

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: capacity=3 and reserved=11 give -8 under the same arithmetic. Changed condition: Remove both calls and leave the definition only. Expected result: No output is printed.

Reason: The body runs only when the function is called.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Positional arguments match parameter names in order. A function definition is not an execution of its body; separate calls supply separate input values.

Limit: The arithmetic permits negative results; a real capacity contract may reject reserved>capacity instead of treating it as free space.

Explain the case, then point to a limit on the claim.
