Reference and your reasoning

  • Main accuracy reference: training16 clear/4 blocked gives an always-clear baseline. On the same20 evaluation cases, reference rows and prediction columns are clear then blocked. Baseline [[16,0],[4,0]], candidate [[12,4],[0,4]]. Accuracy=(upper-left+lower-right)/all. Clear-correct fraction=upper-left/first-row-total; blocked-correct fraction=lower-right/second-row-total. Balanced accuracy averages those two fractions equally. Blocked positive: FP=upper-right, FN=lower-left. Undefined fractions are unavailable, not zero.

Main lesson · Section 16

W5 · Report missing-class coverage

Distinguish ordinary accuracy from an unavailable class fraction.

Reference and your reasoning

  • Main accuracy reference: training16 clear/4 blocked gives an always-clear baseline. On the same20 evaluation cases, reference rows and prediction columns are clear then blocked. Baseline [[16,0],[4,0]], candidate [[12,4],[0,4]]. Accuracy=(upper-left+lower-right)/all. Clear-correct fraction=upper-left/first-row-total; blocked-correct fraction=lower-right/second-row-total. Balanced accuracy averages those two fractions equally. Blocked positive: FP=upper-right, FN=lower-left. Undefined fractions are unavailable, not zero.

  • The supplied scores(counts) function requires nonzero counts for both reference classes and raises ValueError otherwise. It does not return ordinary accuracy in that branch; you may calculate ordinary accuracy separately from the observed counts. There is no measured blocked-class result when no blocked cases exist.

  • An evaluation contains ten clear cases and no blocked cases. All predictions are clear. State ordinary accuracy, explain why blocked performance is unavailable, and describe how our code handles the missing class.
