  • Use this reference for the original W1–W3 and W5 exercises. The separately named independent case supplies its own changed facts; use those facts for that attempt before feedback.

  • A network connects layers so that the output vector of one layer becomes the input vector of the next. Use a fictional numerical input x = [x1, x2].

    The first layer computes z1 = x1 - x2 and z2 = x1 + x2 - 2, then applies ReLU separately: h1 = max(0, z1), h2 = max(0, z2). Its output is the ordered vector h = [h1, h2].

  • The next layer computes y = 2h1 - h2 + 1. It receives h, not the original x. It uses weights [2, -1] and bias 1, with identity as its output activation.

    This is a two-layer computation when counting the layers with weights; an input placeholder is not counted here. All parameters are supplied, so this lesson performs no training.

  • The two first-layer units both receive the same original x. They can be calculated in either order. Only after both activations are available do we evaluate the output layer.

Compose two hidden detectors before one output instead of skipping a layer. Supplied facts: For input [u, v], h1=ReLU(u-2), h2=ReLU(v-1), y=h1-h2. Input [4, 3].

02. Follow the deciding steps

First hidden unit: u-2=2, so h1=2. → Second hidden unit: v-1=2, so h2=2. → Compose output: y=2-2=0; the output uses activated hidden values, not raw inputs.

04. Change one thing. Trace what follows.

Original case: y=2-2=0; the output uses activated hidden values, not raw inputs. Changed condition: Change only v from 3 to1. Expected result: h1 stays 2, h2 becomes 0, y becomes 2.

Reason: The second hidden unit’s preactivation reaches 0 while the first unit is unchanged.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Composition means one layer’s result becomes the next layer’s input. Compute both hidden units before combining them. At [4,3], their equal outputs cancel.

Lowering only the second input removes its positive hidden contribution, so subtracting it no longer reduces the output. The final subtraction must use activated hidden values rather than the raw measurements.

Limit: Hand-composed detectors illustrate layer order; they are not evidence of a learned or biologically realistic neural mechanism.

Explain the case, then point to a limit on the claim.
