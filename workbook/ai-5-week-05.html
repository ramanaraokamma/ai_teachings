Compose two hidden detectors before one output instead of skipping a layer.

Practice 1: explain the deciding evidence

Which labelled step matches this detail? y=2-2=0; the output uses activated hidden values, not raw inputs.

1. Compose output

2. Second hidden unit

3. First hidden unit

Hint if needed: Read the steps in the pictorial case. Match the supplied detail to the stage that performs or records it.

After your attempt, compare with the supported explanation: Compose output y=2-2=0; the output uses activated hidden values, not raw inputs. Composition means one layer’s result becomes the next layer’s input. Compute both hidden units before combining them. At [4,3], their equal outputs cancel. Lowering only the second input removes its positive hidden contribution, so subtracting it no longer reduces the output. The final subtraction must use activated hidden values rather than the raw measurements.

Practice 2: explain the deciding evidence

Changed-case practice: Change only v from 3 to1. Which conclusion is supported by the supplied facts?

1. h1 stays2, h2 becomes0, y becomes2.

2. We can decide the result without examining the changed input or the procedure.

3. This one example guarantees correct results for every future input.

Hint if needed: Use the changed condition and the deciding step in the pictorial trace. The answer must say what follows from those facts.
