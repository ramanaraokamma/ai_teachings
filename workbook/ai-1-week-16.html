01. Boundaries and 'Not Sure': the case

A fictional cubby selector accepts a block if width is at most 5 cm. Supplied facts: An unclear measurement means Block A is either 4 or 5 cm; Block B is either 5 or 6 cm.

These complete possibility sets contain all widths under consideration. Other dimensions are known to fit.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Block A possibilities: 4 and 5 both satisfy the width limit, which includes equality. → Block B possibilities: 5 fits; 6 does not. → Compare decisions: A has one supported decision; B’s possible decisions disagree. → Review B: Ask a named reviewer to remeasure B using the specified width unit.

Point to each numbered stage and explain which recorded input it uses.

03. Possibilities and decisions

Possibilities and decisions. Block A: Width 1 cm = 4, Decision 1 = fits, Width 2 cm = 5, Decision 2 = fits. Block B: Width 1 cm = 5, Decision 1 = fits, Width 2 cm = 6, Decision 2 = fails.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Ask a named reviewer to remeasure B using the specified width unit. Changed condition: Change B’s possibilities to 6 or 7 cm.

Expected result: Both fail the width limit; rejection no longer depends on resolving their difference. Reason: All remaining possibilities lead to the same decision.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Uncertainty about a number need not always create uncertainty about the decision. Every allowed width for A fits, so its width uncertainty does not affect acceptance. B straddles the boundary.

Record both possibilities and request a better measurement instead of selecting the one that makes a preferred outcome. Limit: A review path is not automatically accurate; its conclusion depends on relevant, better evidence.

Explain the case, then point to a limit on the claim.
