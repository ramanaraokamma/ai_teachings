Lesson reference for workbook practice

Use this reference for the original W1–W3 and W5 exercises. The separately named independent case supplies its own changed facts; use those facts for that attempt before feedback.

Use the same restricted network h = ReLU(x), y = vh, with only v trained. Keep the fictional training pairs (1, 2) and (2, 4), start v = 0, and use one full-data batch per update.

Compare rates 0.05, 0.2, 0.3, 0.4 and 0.5 for exactly four updates each. Restart at zero for every run.

The training objective is ordinary MSE: L(v) = 2.5 times (v - 2) squared. Its gradient is 5 times (v - 2). A step is new v = v - rate times 5 times (v - 2).

This small quadratic lets us explain each result rather than treating the rate as a magic setting.

02. Follow the deciding steps

Rate 0.25: First a = 2, loss 4; second a = 3, loss 1. → Rate 0.75: First a = 6, loss 4; second a = 3, loss 1. → Inspect paths: Both end at 3 and loss 1; larger rate crosses the optimum while smaller rate stays below it.

Point to each numbered stage and explain which recorded input it uses.

03. The update factor explains three behaviours

The update factor explains three behaviours. 0.05 gives 0.75 | Same side and shrinking | Multiplied by 0.5625. 0.3 gives -0.5 | Alternating and shrinking | Multiplied by 0.25. 0.5 gives -1.5 | Alternating and growing | Multiplied by 2.25

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Both end at 3 and loss 1; larger rate crosses the optimum while smaller rate stays below it. Changed condition: Add a rate 1 run from a = 0. Expected result: Its path is 8 then 0, with loss 16 at both steps.

Reason: The update alternates across 4 without reducing the initial loss.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Keep the starting parameter and update budget identical to compare rates fairly. Rate one-quarter approaches the optimum from below; rate three-quarters crosses it and comes back.

Their final losses happen to match after two updates, despite different paths. Rate one repeatedly overshoots by the same distance, so using the correct gradient alone does not ensure improvement.

Limit: These quadratic paths explain step size. Real nonconvex networks can have more complicated rate behaviour.
