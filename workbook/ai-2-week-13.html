01. Types of Classification Error: the case

A fictional book-condition checker predicts repair or sound. Supplied facts: Use reference rows and prediction columns in order sound,repair. Repair is positive.

Six reference/prediction pairs: sound/sound twice; sound/repair once; repair/sound once; repair/repair twice.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Declare axes: Rows: reference sound,repair.

Columns: predicted sound,repair. → Fill sound row: Two true negatives and one false positive: [2,1]. → Fill repair row: One false negative and two true positives: [1,2]. → Read result: Matrix [[2,1],[1,2]]: agreement 4/6, repair recall 2/3.

Point to each numbered stage and explain which recorded input it uses.

03. Reference rows, prediction columns

Reference rows, prediction columns. Reference sound: Predicted sound = 2, Predicted repair = 1. Reference repair: Predicted sound = 1, Predicted repair = 2.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Matrix [[2,1],[1,2]]: agreement 4/6, repair recall 2/3. Changed condition: Change one repair/sound prediction to repair/repair after a real model revision.

Expected result: Repair row becomes [0,3]; agreement becomes 5/6. Reason: One false negative moves to true positive; the sound row stays [2,1].

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Each case enters one cell according to its reference and predicted label. The off-diagonal cells represent different mistakes: a false alarm on a sound book versus a missed repair.

Trace the cell definitions before naming rates; swapping axes changes the table’s interpretation even if its diagonal sum remains unchanged.

Limit: Reference labels can themselves be disputed; a true-positive name does not guarantee the annotation is infallible.

Explain the case, then point to a limit on the claim.
