01. Structured Output and Schemas: the case

A fictional Study Buddy returns a machine-readable book fact. Supplied facts: Schema: exactly title text, pages integer, source_id text. Approved record R: River Notes, 64 pages.

X={"title":"River Notes","pages":64,"source_id":"R"}; Y uses pages:"64"; Z uses pages:46 with otherwise identical fields.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Parse: Each shown object is valid JSON syntax. → Schema check: Y fails because its pages value is text, not an integer. → Meaning check: Z fits field types but contradicts R’s page count. → Accept X: X passes syntax, declared schema and source comparison.

Point to each numbered stage and explain which recorded input it uses.

03. Keep the evidence roles separate

Keep the evidence roles separate. Generated text | JSON parse | A value or syntax error. Parsed value | Closed-schema check | Contract match or schema error.

Contract-valid object | Match claims to current sources | Supported or semantic error

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: X passes syntax, declared schema and source comparison. Changed condition: Add an extra field "rating":5 to X under the exactly-fields schema.

Expected result: The changed object fails schema despite keeping the correct page count. Reason: Exactly means additional fields are not allowed in this contract.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Parsing establishes that text forms a structured object. Schema checks establish required fields and types. Semantic validation compares their meaning with the approved source.

These are different layers: a parseable, well-shaped object can still contain a false fact. Report the first failing layer without treating format success as factual success.

Limit: Source agreement does not establish that the approved catalogue itself is correct or complete.

Explain the case, then point to a limit on the claim.
