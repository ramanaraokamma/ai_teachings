01. Similarity by Selected Traits: the case

A fictional toy book matcher represents two preferences with numeric features. Supplied facts: Target vector [2,5]. Candidate A=[2,2], B=[4,5], C=[3,4].

Use Manhattan distance: add absolute coordinate differences; return all smallest-distance candidates.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Distance A: |2−2|+|5−2|=0+3=3. → Distance B: |2−4|+|5−5|=2+0=2. → Distance C: |2−3|+|5−4|=1+1=2. → Choose closest: B and C tie at distance 2; keep the tie visible.

Point to each numbered stage and explain which recorded input it uses.

03. Toy feature positions

Toy feature positions. A: (2, 2). B: (4, 5). C: (3, 4). Query Target: (2, 5). Axes: first toy feature; second toy feature. Distance: Manhattan distance; horizontal=first feature, vertical=second feature.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: B and C tie at distance 2; keep the tie visible. Changed condition: Give the first-coordinate difference weight 2 while the second keeps weight 1. Expected result: Distances become A=3, B=4, C=3; A and C tie.

Reason: The representation’s comparison rule changes; the supplied vectors stay the same.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Each coordinate contributes according to the declared distance rule. Smaller distance means closer in this representation, not automatically a better reading experience.

If one coordinate uses a much larger numerical scale, it can dominate the sum even when it is not more important. Feature units and scaling belong in the method record.

Limit: A toy numeric encoding does not establish meaningful interpersonal distances or suitability of a recommendation.

Explain the case, then point to a limit on the claim.
