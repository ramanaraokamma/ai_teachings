Practice 1: explain the deciding evidence

Which labelled step matches this detail? Also plan invalid request, no eligible item and equal-score cases.

1. Filter and rank

2. Specify inputs

3. Acceptance cases

Hint if needed: Read the steps in the pictorial case. Match the supplied detail to the stage that performs or records it.

After your attempt, compare with the supported explanation: Acceptance cases Also plan invalid request, no eligible item and equal-score cases. Planning fixes what success means before code returns an answer. The duration boundary is including equality, and the tie policy prevents accidental list-order dependence. A complete output may include why other rows were excluded. Test expectations should come from the contract rather than copying the first program result.

Practice 2: explain the deciding evidence

Changed-case practice: Reduce the limit from 8 to 5. Which conclusion is supported by the supplied facts?

1. This one example guarantees correct results for every future input.

2. Return no eligible item.

3. We can decide the result without examining the changed input or the procedure.

Hint if needed: Use the changed condition and the deciding step in the pictorial trace. The answer must say what follows from those facts.

After your attempt, compare with the supported explanation: Return no eligible item. All three valid rows take more than five minutes.
