W1 · Explain the current example

Keep this task’s inputs,rule and response together.

Complete task and evidence

  • A cache stores a previous result for possible reuse. Check current trusted permission before serving a value. The classroom key is query, trusted role, corpus version and procedure version. Use virtual minutes: age = now minus saved time; valid age satisfies 0 ≤ age < TTL, so equality expires.

    Main TTL 5: a teacher c1/p1 entry saved at 0 hits at 4 only with permission; a student same-query request misses, revoked permission denies, and age 5 expires. Corpus c2 or procedure p2 misses even at age 1. Separate picture: approved version 5 says 09:30, while saved version 4 says 09:00.

    Hold role/procedure fixed; first version 5 request misses, an authorized local fixture lookup supplies 09:30, and a later matching fresh request may hit. Silent unversioned source edits cannot be detected by the same key and TTL. Roles and permissions are supplied fixtures, not a login system; finer access differences require additional key scope.

    Freshness does not establish truth, and expiry does not prove retention deletion. The code uses copied fictional dictionaries and virtual times only.
