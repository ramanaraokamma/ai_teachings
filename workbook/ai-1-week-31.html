01. Design the Decision Process: the case

A fictional worksheet routes craft kits by required glue and number of scissors. Supplied facts: K1: glue No, scissors 2. K2: glue Yes, scissors 2. K3: glue Yes, scissors 4. Request: glue required Yes, scissors needed 2.

Return first kit meeting both requirements.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Validate fields: Require Yes/No glue input and whole scissors count 0–4. → Evaluate K1: Scissors fit, but required glue is absent: continue. → Evaluate K2: Glue is present and 2 scissors meet the request: accept. → Stop: Return K2 without replacing it with later K3.

Point to each numbered stage and explain which recorded input it uses.

03. Four paths through the recommender

Four paths through the recommender. Input missing or invalid | Ask for corrected input | Stop this run. Candidate fails a check | Move to the next row | Continue search.

Candidate passes both | Suggest it with a reason | Stop this run. All rows checked and failed | Report no match | Stop this run

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Return K2 without replacing it with later K3. Changed condition: Increase scissors needed to 3. Expected result: K3 is selected. Reason: K1 lacks glue; K2 has only 2 scissors; K3 has glue and 4.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

A complete decision process specifies what to do after each result. One passing requirement is insufficient.

After a kit passes both, stopping preserves the first-match contract; automatically choosing the largest later kit would implement a different rule. A full scan with no accepted kit returns no match.

Limit: A correct flow depends on accurate catalogue entries and the declared requirements; the picture does not verify inventory.

Explain the case, then point to a limit on the claim.
