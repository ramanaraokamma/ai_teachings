# Learning improvements

Implemented in the requested sequence across the website and complete offline programme.

1. **Completed work:** weekly and programme portfolio HTML/JSON exports include learner answers, project reflections and actual Python evidence. Role and week filters prevent teacher responses entering student exports. Offline HTML exports completed work from the current page.
2. **Formative practice:** 528 supported questions across 264 lessons provide hints, feedback and changed cases. Reserved independent tasks and teacher assessment answers remain separate. Practice success is not a mastery score.
3. **Executable Python:** 143 supported examples across 113 lessons use real browser Python in a worker. All examples were executed; one deliberately erroneous index example produces its intended error. Stop controls, fresh globals and a five-second execution limit support debugging. Fictional file fixtures support file examples. The locally bundled runtime is Pyodide 314.0.7; see [official worker documentation](https://pyodide.org/en/stable/usage/webworker.html).
4. **Repair paths:** 719 earlier-lesson links provide focused worked-case review. These are suggested reviews, not automated learner diagnoses.
5. **Accessibility:** improved labels, keyboard navigation, contrast, scrollable code/tables, reduced motion and responsive controls. 24 automated browser audits passed with no detected violations, covering student and teacher pages including the pilot studio at desktop and phone widths; keyboard, zoom, portfolio export, feedback and Python timeout/recovery were exercised. Actual screen-reader user testing has not been performed.
6. **Classroom pilot prepared:** teacher-only studio, three readiness tracks, nine held-back phase-specific learner handouts, reasoning keys, observation CSV and local JSON import/export. Baseline/post/delayed comparisons use anonymous matched records, date ordering and exposure exclusions. Tests use synthetic records only. **No real classroom sessions or learner outcomes have been recorded by this work.** Grade/readiness, group size and teaching dates remain needed to conduct the pilot.

Validation evidence: `learning-tools-coverage.json`, `python-lab-validation.json`, `learning-accessibility-validation.json`, `download-validation.json`, and the repository access checks. All 792 Word and 792 PDF weekly downloads were regenerated and validated against canonical content (14,816 PDF pages). The build and all 276 access and lesson checks passed; all 3,832 protected resources decrypted successfully. Offline real Python execution and saved code restoration passed. Original curriculum preservation checks passed. No deployment was performed.

Use the complete edition in `outputs/ai-academy-complete-programme/`. For offline Python, serve that folder using `python3 -m http.server 8000 --bind 127.0.0.1`, open the local student index and stop the server after use. Reading, printed tasks and exports remain available when opening HTML directly; browser worker execution requires HTTP.
