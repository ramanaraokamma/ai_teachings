Worked explanation · Boolean conditions

With Boolean operands, and needs both parts True. Inclusive or needs at least one True, so both True is allowed. not reverses a Boolean: not True is False and not False is True.

Python can also apply and and or to other types; keep operands Boolean here so this table directly describes the result.

Find and repair a mistake

Find the unsupported step in the Boolean conditions claim and explain a repair using the supplied evidence.

minutes = 12
quiet = True
print((minutes >= 0) and (minutes <= 12))
print(not quiet)
print(minutes == 12)

Check the claim against the facts

This prints True, False and True. Parentheses make the two range checks clear. To express minutes equal to 8 or 12, write (minutes == 8) or (minutes == 12).

Do not write minutes == 8 or 12: the number 12 is not a second equality comparison. Later lessons examine truth testing of other types.

The rule uses values supplied by a person. It does not verify that the activity is really quiet, and a True result grants no permission to act.

Our input contract already assumes a valid integer and Boolean; handling wrong types is a separate task.
