Main lesson · Section 2

Add a declared cost to one specified weight

The penalty changes the objective;it is not another prediction error.

Complete restricted model and penalty definition

Keep h = ReLU(x), y = vh, train only v on (1, 2) and (2, 4), and freeze all hidden parameters and the zero output bias. Training MSE is L(v) = 2.5(v - 2) squared.

Define J(v) = L(v) + lambda times v squared, with lambda nonnegative. Only this one output weight is penalised here.

For lambda = 0.5, the penalty at v = 1.5 is 0.5 times 2.25 = 1.125. Prediction MSE is 0.625, so total objective J is 1.75. Keep these quantities separate in logs.

A smaller total objective does not automatically mean a smaller prediction error.

    Objective convention and helper contract

    Both gradient contributions are evaluated at the same old v. Keep the data term L=2.5(v−2)²and penalty lambda v²separate before adding them. The one-step code assumes finite numbers and nonnegative lambda; it is not a validator or a search for the best penalty.     Use the same declared validation prediction metric for development choices. The early-stopping log later is a separate paper-policy exercise, not a training run generated by these steps.

    Assume finite numeric values and nonnegative penalty. At the new v, data loss is 0.4, penalty 1.28 and total 1.68.

    Choose penalty strength using a declared validation prediction metric, not by comparing total objectives with different lambdas as if they were the same measure.

    Main lesson · Section 7

    Stop when the rule fires,then restore the best observed model

    A later value in a paper log cannot rewrite what a live run observed.

    Complete policy,finite budget and saved-state requirements

    Early stopping limits the training duration using development evidence; it does not add a weight term to the objective. For this policy, initialise the best checkpoint to epoch 0 and the miss count to zero.

    After each later evaluation, save and reset only on a strict improvement; otherwise increment the count. Stop as soon as the count reaches patience, then reload the best checkpoint.

    Suppose a pre-recorded demonstration also lists epoch 7 loss 1.3. A live run following the rule has already stopped at 6 and does not observe 7. Do not use future values to rewrite the stopping decision.

    The policy can miss a later improvement; patience balances waiting against a training budget and must be specified in advance.

    Save actual model parameters with the checkpoint, not just its epoch number or loss. With a fixed maximum epoch budget, stop when either limit is reached and restore the best observed state.

    An exact tie keeps the earlier checkpoint under our rule. Different minimum-improvement thresholds are possible, but would be different declared policies.

    Complete runnable stopping-policy replay

    from math import isfinite

def replay_stopping(losses, patience, first_epoch=0):
    """Replay supplied validation observations; no training or real files are loaded."""
    if not losses or type(patience) is not int or patience < 1:
        raise ValueError('Need observations and positive integer patience')
    best_index = 0
    misses = 0
    trace = []
    stop_index = len(losses) - 1  # finite supplied observation budget
    for i, value in enumerate(losses):
        if not isfinite(value) or value < 0:
            raise ValueError('Observed MSE must be finite and nonnegative')
        if i == 0:
            decision = 'save initial best'
        elif value < losses[best_index]:
            best_index, misses = i, 0
            decision = 'save improved best'
        else:
            misses += 1
            decision = 'stop; select saved best' if misses >= patience else 'wait'
        trace.append((first_epoch + i, value, misses, first_epoch + best_index, decision))
        if misses >= patience:
            stop_index = i
            break  # do not inspect or select from later supplied observations
    return first_epoch + stop_index, first_epoch + best_index, trace

# Separate supplied paper logs; values are not generated by the penalty code.
main = [4, 2, 1.5, 1.6, 1.4, 1.45, 1.46, 1.3]
stop, best, observed = replay_stopping(main, patience=2)
print('main stop / selected saved epoch', stop, best)
print('observed trace: epoch, loss, misses, best epoch, action')
for row in observed:
    print(row)
print('picture patience 1, checkpoints numbered from 1:', replay_stopping([5,3,3,4], 1, 1)[:2])
print('picture patience 2, checkpoints numbered from 1:', replay_stopping([5,3,3,4], 2, 1)[:2])
print('Policy decisions replayed. Actual saved model files are not supplied or restored by this program.')
