Main lesson · Section 2

Define MAE, MSE and RMSE before comparing models

The operation and unit tell the reader what a reported number means.

Complete loss definitions and fictional scope

A loss summarizes error magnitude without positive and negative cancellation. MAE averages absolute residuals. MSE averages squared residuals and penalizes large magnitudes more strongly.

RMSE takes the square root of MSE so it returns to the target unit. These are different questions, not interchangeable labels.

Main lesson · Section 3

Trace magnitudes, squares and the square root in order

The same residuals produce different summaries.

Complete worked residuals and calculations

Residuals [-1, 2,-3] cm have absolute errors [1, 2, 3], so MAE=6/3=2 cm. Squared errors [1, 4, 9] sum to 14, so MSE=14/3 square cm and RMSE=sqrt(14/3), about 2.16 cm. Keep the square and the average in the correct order.

Optional original calculation script

from math import sqrt
residuals = [-1, 2, -3]
mae = sum(abs(r) for r in residuals) / len(residuals)
mse = sum(r * r for r in residuals) / len(residuals)
print(mae, mse, sqrt(mse))
# About 2.0, 4.67, 2.16.
# MAE and RMSE: cm. MSE: square cm.

Optional complete guarded loss program

import math


def losses(residuals):
    if not residuals:
        raise ValueError('No observed average loss without records')
    if any(type(r) not in (int, float) or not math.isfinite(r) for r in residuals):
        raise ValueError('Need finite matched residuals in one declared unit')
    mae = sum(abs(r) for r in residuals) / len(residuals)
    mse = sum(r * r for r in residuals) / len(residuals)
    return {'mae': mae, 'mse': mse, 'rmse': math.sqrt(mse)}


training_heights = [5, 7, 9]  # Fit the constant before evaluating new cases.
baseline = sum(training_heights) / len(training_heights)
observed = [10, 10, 10]      # E1, E2, E3, three different fictional objects.
candidate = [10, 10, 4]     # Supplied predictions; candidate fitting not given.
baseline_predictions = [baseline] * len(observed)
for name, predictions in [('candidate', candidate), ('mean baseline', baseline_predictions)]:
    residuals = [y - p for y, p in zip(observed, predictions)]
    print(name, residuals, losses(residuals))
# Length/order/unit identity is declared by the supplied matched E1–E3 fixture.
# Different losses can rank the same fixed predictions differently.
