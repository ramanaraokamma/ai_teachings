Main lesson · Section 2

Summarize four complete non-overlapping windows

Max and mean are separate fixed operations on the same input.

Complete feature map and window rule

A fictional single-channel feature map has rows [1, 4, 2, 0], [3, 2, 5, 1], [0, 6, 1, 3] and [2, 4, 2, 7]. Use a 2 by 2 window, stride 2, no padding and only complete windows. Coordinates are zero-based.

The four starts are [0, 0], [0, 2], [2, 0] and [2, 2].

Max pooling keeps the largest value in each window. Mean pooling adds the four values and divides by 4. Neither operation learns weights in this lesson.

These are fixed summaries of the incoming feature map, unlike the trainable kernel parameters introduced last week.

Output shape and retained coarse arrangement

The max output is [[4, 5], [6, 7]], and the mean output is [[2.5, 2], [3, 3.25]]. Both have shape 2 by 2. Sixteen values become four, but the four outputs still preserve the coarse arrangement of the four regions.

    Complete function scope and boundary assumptions

    This code assumes a nonempty rectangular numeric map at least 2 by 2. It uses only complete 2 by 2 windows, stride 2 and no padding.

    It returns two separate summaries of the same map; it does not apply one pooling operation after the other.

    For this complete-window rule the output shape is floor((H - 2) / 2) + 1 by floor((W - 2) / 2) + 1. A 3 by 3 map produces just one output; its last row and last column are not read.

    Do not silently invent a partial-window rule or pad missing positions.

    Separate summaries and information contract

    The two output maps preserve which coarse region produced each scalar. They do not preserve the four original positions and values within that region. pool 2 returns maxima and means separately from the original map. It requires a nonempty rectangular numeric input and checks that at least one 2×2 window fits. Only complete windows at stride 2 are read; with a3×3 input, the last row and column are excluded.

    This boundary rule is part of the operation, not a discovered property of the data.

    Complete runnable max/mean pooling

    def pool2(image):
    h, w = len(image), len(image[0])
    if h < 2 or w < 2:
        raise ValueError("Need a complete 2 by 2 window")
    maxima, means = [], []
    for r in range(0, h - 1, 2):
        max_row, mean_row = [], []
        for c in range(0, w - 1, 2):
            values = [image[r+i][c+j]
                      for i in range(2) for j in range(2)]
            max_row.append(max(values))
            mean_row.append(sum(values) / 4)
        maxima.append(max_row)
        means.append(mean_row)
    return maxima, means

    Main lesson · Section 7

    Test movement across a boundary and all-negative windows

    Pooling preserves some rearrangements,not every spatial change.

    Complete boundary,negative-value and max-position limits

    Within one isolated window, rearranging its values preserves both its maximum and mean. But moving a value across a window boundary can change the output map. In a 2 by 4 map of zeros, put a single 8 at row 0 column 1.

    Max pooling gives [[8, 0]]. Move that 8 one column right to column 2, replacing the old position with zero: the output becomes [[0, 8]]. Pooling therefore does not guarantee that a classifier ignores every small movement.

    Negative values are valid inputs. For [[-4, -2], [-7, -3]], the maximum is -2 and the mean is -4. Starting a maximum calculation at zero would incorrectly return 0.

    Adding a zero to the window would also change its maximum: padding choices matter. Our examples use no padding.

    Returning the position of a maximum can preserve extra location information, but it still does not restore the discarded values.

    For example, [[5, 1], [2, 3]] and [[5, 0], [0, 0]] have the same unique maximum 5 at the top-left position. Even the maximum plus its position cannot tell which original window was used.

def max_with_position(window):
    candidates = [(value, r, c) for r,row in enumerate(window) for c,value in enumerate(row)]
    # Row-major first position wins a tie; these two probes have a unique maximum.
    value, r, c = max(candidates, key=lambda item: item[0])
    return value, (r,c)

print('max plus position still collides:',
      max_with_position([[5,1],[2,3]]),max_with_position([[5,0],[0,0]]))
