Student lesson · 2 of 14

Notice the evidence

A small fictional RGB image has height 2 pixels, width 2 pixels and three channels ordered red, green, blue. Store it as image[row][column][channel], abbreviated HWC. Use zero-based indices: the top row is 0, the left column is 0, and red, green and blue are channels 0, 1 and 2. Each stored component is an integer from 0 to 255.

PositionRGB tripletMeaning
Row 0 column 0[255, 0, 0]Red
Row 0 column 1[0, 255, 0]Green
Row 1 column 0[0, 0, 255]Blue
Row 1 column 1[255, 255, 255]White

The shape is 2 by 2 by 3. There are four pixels and twelve channel values. The blue component of the bottom-left pixel is image[1][0][2] = 255. A single channel is a plane of values across positions; it is not a separate photograph or a label.

Shape needs a schema. A grayscale image might be stored as H by W or H by W by 1. An RGB image uses three channels here; other formats can include additional channels. Declare the format instead of assuming every three-dimensional array means the same thing.

Student lesson · 3 of 14

See how it works

A channel-first layout uses image[channel][row][column], abbreviated CHW. Our image then has shape 3 by 2 by 2. A correct conversion preserves the rule chw[c][r][k] = hwc[r][k][c]. The code assumes a nonempty rectangular image with exactly three values per pixel.

hwc = [
    [[255, 0, 0], [0, 255, 0]],
    [[0, 0, 255], [255, 255, 255]],
]
height, width = len(hwc), len(hwc[0])
chw = [[[hwc[r][k][c] for k in range(width)]
        for r in range(height)] for c in range(3)]
for channel in chw:
    print(channel)
assert chw[2][1][0] == hwc[1][0][2] == 255
restored = [[[chw[c][r][k] for c in range(3)]
             for k in range(width)] for r in range(height)]
assert restored == hwc

Reading nested values in order and merely regrouping them into a new shape does not perform this axis conversion. The first four flattened HWC values are [255, 0, 0, 0]. A naive regrouping makes these the first channel plane, but the correct red plane is [[255, 0], [0, 255]]. Shape agreement alone cannot detect this mistake.

A pictorial worked case: Image tensors and channels

Move colour values between tensor layouts without changing the pixels.

The facts we will use

Toy RGB image has 2 rows, 1 column. Top pixel [1, 4, 7]; bottom [2, 5, 8]. HWC means height, width, channel.

All inputs and outcomes in this worked example are invented classroom data; no real model run is claimed.

Why this result follows

A tensor is an array with named dimensions. HWC orders height, width and colour; CHW puts colour first. Rearranging the layout changes where values are stored, not the colour measurement itself. Trace a named pixel through both layouts using zero-based indices. Adding a batch dimension counts images and does not add a new colour channel.

What this example does not establish

Shape consistency does not prove correct colour order or value range; document channel names and preprocessing.

Student lesson · 7 of 14

Find and repair a mistake

For this lesson, divide every channel value by 255 to obtain floating-point values from 0 to 1. Thus [255, 128, 0] becomes [1, 128/255, 0], with the middle value approximately 0.502. This fixed conversion does not fit a statistic from data. Apply the same conversion during training and later use, and record whether an input is already scaled.

Dividing twice makes a raw value of 255 become 1/255, approximately 0.00392, instead of 1. Integer rounding after scaling can also erase distinctions. In exact arithmetic the declared division is reversible by multiplication; finite precision or deliberate rounding can limit exact recovery.

Averaging RGB channels is a different operation. The classroom mean gives red [255, 0, 0] and green [0, 255, 0] the same value 85, losing their colour distinction. It is a simple illustration, not a perceptual brightness formula. If preprocessing instead estimates means or spreads from a dataset, fit those statistics using training data only.

Locate the earliest unsupported step

Scale [255, 128, 0] by 255, keeping the middle value as a fraction. Then calculate the classroom RGB means of pure red and pure green. Which operation loses the distinction between those colours?

Show what you know

Stacking five same-size HWC images adds a leading example axis N. This batch has shape 5 by 2 by 2 by 3 and contains 60 channel values. With channel-first images, its shape is 5 by 3 by 2 by 2. The example axis is not another colour channel. Every axis must keep its meaning through the model.

Use a tiny known image, named axis meanings and expected channel values to check a pipeline. Keep original images when testing transformations. Flattening can be reversed if shape and traversal order are retained; averaging colours generally cannot. Next week reads small neighbourhoods with a convolution operation.
