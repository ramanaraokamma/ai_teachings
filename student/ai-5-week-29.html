Class definition and selected-class confidence

A model can be confidently wrong. Use these supplied outputs for a fictional image classifier: class 1 means a triangle is present; class 0 means it is absent.

The values p1 are probability estimates for class 1, invented for this exercise rather than produced by a trained model. Predict 1 when p1 >= 0.5 and 0 otherwise. The selected-class confidence is max(p1, 1 - p1).

Reference labels are supplied for this exercise; real investigations must check their quality too.

Calibration needs many comparable cases

A score alone cannot establish reliability. Calibration asks whether, across many comparable cases, predictions assigned a probability such as 0.90 are correct about 90 percent of the time.

One correct or incorrect case cannot answer that question.

    Runnable original report

    rows = [(0.95, 1), (0.90, 0), (0.80, 1),
        (0.60, 0), (0.45, 0), (0.10, 1)]

def report(rows, cutoff):
    if not rows or not 0.5 <= cutoff <= 1:
        raise ValueError("Need rows and cutoff in [0.5, 1]")
    correct = accepted = accepted_correct = 0
    for p1, label in rows:
        if not 0 <= p1 <= 1 or label not in (0, 1):
            raise ValueError("Invalid score or label")
        pred = int(p1 >= 0.5)
        ok = int(pred == label)
        correct += ok
        if max(p1, 1 - p1) >= cutoff:
            accepted += 1
            accepted_correct += ok
    return (correct / len(rows), accepted / len(rows),
            accepted_correct / accepted if accepted else None)

print(report(rows, 0.8))  # (0.5, 4/6, 0.5) approximately

    Denominators, boundaries and undefined accuracy

    The function returns overall accuracy, coverage and accuracy among accepted cases. It assumes numeric scores and binary labels. None means no cases were accepted, so accepted-case accuracy is undefined, not zero or perfect.

    Keep counts with proportions and declare the comparison at the boundary.

      Complete executable multi-cutoff audit

      """Invented development scores; no model or human-review run is claimed."""
from math import isfinite
rows = [('A', 'clear', .95, 1), ('B', 'blurred', .90, 0),
        ('C', 'clear', .80, 1), ('D', 'blurred', .60, 0),
        ('E', 'clear', .45, 0), ('F', 'blurred', .10, 1)]
def report(rows, cutoff):
    if not rows or not isfinite(cutoff) or not .5 <= cutoff <= 1:
        raise ValueError('Need rows and finite cutoff in [0.5,1]')
    ledger = []
    for name, condition, p1, label in rows:
        if not isfinite(p1) or not 0 <= p1 <= 1 or label not in (0,1):
            raise ValueError('Invalid score or binary reference')
        pred = int(p1 >= .5)
        confidence = max(p1, 1-p1)
        ledger.append((name, pred, confidence, pred == label,
                       confidence >= cutoff))
    accepted = [r for r in ledger if r[4]]
    return {'ledger': ledger, 'total': len(rows),
            'correct': sum(r[3] for r in ledger),
            'accepted': [r[0] for r in accepted],
            'deferred': [r[0] for r in ledger if not r[4]],
            'coverage': len(accepted)/len(rows),
            'accepted_accuracy': (sum(r[3] for r in accepted)/len(accepted)
                                  if accepted else None)}
for cutoff in [.5, .8, .95, .99]:
    print(cutoff, report(rows, cutoff))
r = report(rows, .8)
assert r['accepted'] == ['A','B','C','F']
assert r['deferred'] == ['D','E']
assert r['correct'] == 3 and r['accepted_accuracy'] == .5
assert report(rows,.99)['accepted_accuracy'] is None
confusion = {'TP':0, 'TN':0, 'FP':0, 'FN':0}
for _, _, p1, label in rows:
    pred = int(p1 >= .5)
    key = ('TP' if label else 'FP') if pred else ('FN' if label else 'TN')
    confusion[key] += 1
assert confusion == {'TP':2,'TN':1,'FP':2,'FN':1}
print('Confusion counts:', confusion)
for condition in ['clear','blurred']:
    group = [r for r in rows if r[1] == condition]
    print(condition, report(group,.8)['correct'], '/',len(group))
