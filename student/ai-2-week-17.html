Main lesson · Section 3

Trace mean and odd-count median with complete Python

Explain the count and sorted position before trusting the output.

Predict and run the five-value script

values = [2, 3, 3, 4, 18]
ordered = sorted(values)
mean = sum(values) / len(values)
median = ordered[len(ordered) // 2]
print(mean)
print(median)

Read the syntax and its limited contract

sum adds all observations, including repeated values; len counts observations, not distinct numbers. sorted makes a separate ordered list. With five entries, len//2 is2, so zero-based position2 is the third value. That shortcut selects the median only for a nonempty odd count. The original list is preserved for checking against the source.

The script prints 6.0 and 3. sorted returns a sorted list without changing the original. This median expression works for a nonempty odd-length list only. For four sorted values, average the second and third.

Do not use this odd-length shortcut for every dataset.

Compare the two summary questions

The mean shares the total equally: 2 + 3 + 3 + 4 + 18 is 30, and 30 divided by five is 6. The median asks for the middle value after sorting: the third value is 3.

The long duration 18 pulls the mean upwards but leaves the middle value at 3. A difference between the summaries is a clue to inspect the data, not permission to remove the inconvenient value.

      Main lesson · Section 8

      Sort first and handle even and empty lists explicitly

      Do not reuse an odd-count shortcut as a universal median procedure.

      Compare unsorted position with sorted median

      Taking the middle item of an unsorted list can give the wrong median. For [18, 2, 4, 3, 3], the middle item is 4, but the sorted median is 3. Sort first. For an empty list, there is no mean or median under this lesson's rules.

      Read the complete three-case extension

      def summaries(values):
    if not values:
        return None, None
    ordered = sorted(values)
    middle = len(ordered) // 2
    if len(ordered) % 2 == 1:
        median = ordered[middle]
    else:
        median = (ordered[middle - 1] + ordered[middle]) / 2
    mean = sum(values) / len(values)
    return mean, median

for values in [[2, 3, 3, 4, 18], [8, 2, 4, 6], []]:
    print(summaries(values))

      Explain empty, odd and even branches

      This extended function assumes finite numeric observations in consistent units. %2 gives remainder1 for an odd count. For an even count, average positions middle-1 and middle in the sorted list. The empty branch returns None,None to mean unavailable, not measured zero. The outputs are (6.0,3), (5.0,5.0) and (None,None). The function does not decide whether an unusual value is a valid measurement.
