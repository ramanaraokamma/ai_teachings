Connect five block actions to executable code

Block actionPython and effect
Set counter oncecount = 0 before the loop
Repeat for each bookfor pages in page_counts:
Test the strict ruleif pages < 100:
Increase qualifying countcount = count + 1, inside the condition
Finish the functionreturn count after the loop; print the returned result
def count_short_books(page_counts):
    # Supplied input: a list of nonnegative integer page counts.
    count = 0
    for pages in page_counts:
        if pages < 100:
            count = count + 1
    return count

print(count_short_books([80, 150, 90]))
print(count_short_books([80, 150, 100]))
print(count_short_books([]))
