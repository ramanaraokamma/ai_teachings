State the reusable calculation

A fictional supply cupboard records capacity and the number of occupied spaces. The remaining-space calculation is capacity minus used.

Instead of copying the same instructions for every cupboard, define one function and call it with different values. A function makes a procedure reusable; its name alone does not guarantee that its instructions are correct.

Read the assumed valid inputs and scope

Our input contract requires nonnegative integer counts with used no greater than capacity. The example assumes these conditions; it does not validate them. The main cupboard function prints its result. The labelled extension shows a different interface: returning a value for the caller to use or display.

      Main lesson · Section 8

      Practise: expose fixed constants and missing arguments

      Preserve the faulty version before making the targeted repair.

      Read the faulty reusable-looking function

      def show_remaining(capacity, used):
    remaining = 12 - 4
    print(remaining)

show_remaining(12, 4)
show_remaining(10, 7)

      Locate and replace the fixed-number expression

      This faulty function prints 8 twice. Its fixed numbers ignore the arguments. Replace 12 - 4 with capacity - used, then rerun both calls.

      Testing only the first call would miss the bug because its expected answer happens to be 8.

      Distinguish a call from a name and a missing argument

      For this two-parameter definition, show_remaining(12) raises TypeError because an argument is missing. Correct the call to supply both values.

      Naming a function without calling it does not execute the body: the parentheses in show_remaining(12, 4) are part of the call.
