Explain the inclusive boundary and ordered decisions

Only A is printed, with score 10. If B took 20 minutes it would qualify and have the higher score 11. The inclusive boundary matters.

Ratings and weights are invented for practice and require justification before use in a real decision.

Make two decisions in order. First check the duration: A takes 15 minutes and qualifies under the 20-minute limit; B takes 25 minutes and does not. Then calculate scores for eligible choices. A scores 2 times 4 plus 2, or 10.

B would score 11, but that score cannot remove the time requirement. Keep the rejection reason beside B instead of calling it a worse-scoring activity.

State input assumptions and omitted review handling

This short script assumes the named fields are present, fun/learning are valid whole-number0–5 ratings and minutes is a nonnegative whole number. It demonstrates the time constraint and scoring; it is not a complete input validator. A missing field must not be silently treated as0. Keep rejected items and reasons in the investigation record even though this minimal script prints only eligible choices.

      The complete input-validation and scoring program

      options = [{"id": "A", "interest": 3, "practice": 2, "minutes": 14},
           {"id": "B", "interest": 4, "practice": 3, "minutes": 15},
           {"id": "C", "interest": 2, "practice": 5, "minutes": 12}]
limit = 14
for interest_weight in [2, 3]:
    scores = {}
    review = []
    for item in options:
        values = [item.get(key) for key in ["interest", "practice", "minutes"]]
        if not all(type(value) is int and value >= 0 for value in values):
            review.append((item["id"], "missing or invalid input"))
        elif item["minutes"] > limit:
            review.append((item["id"], "exceeds time limit"))
        else:
            scores[item["id"]] = interest_weight * item["interest"] + item["practice"]
    print("weight", interest_weight, "scores", scores, "review", review)
    if not scores:
        print("No eligible option")
    else:
        highest = max(scores.values())
        tied = sorted(name for name in scores if scores[name] == highest)
        print("top", tied, "chosen", tied[0])
