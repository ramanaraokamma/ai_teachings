    Return hands back data; the caller chooses how to use it

    A caller assignment stores the returned value under a different name.

    Complete return-and-combine program

    def remaining(capacity, used):
    spaces = capacity - used
    return spaces

first = remaining(12, 4)
second = remaining(10, 7)
print(first + second)

    Trace the two local calculations

    Separate return, assignment and display

    Execution eventReturned valueCaller binding / displayed output
    remaining(12,4) computes local spaces8Assignment binds first=8; no output
    remaining(10,7) computes its own spaces3Assignment binds second=3; first still 8
    print(first+second)No new function result neededDisplay 11
    Remove outer print onlyReturn values still storedNo output from this script

    Read execution after return

    return spaces ends the current function call and sends the value of spaces back. The assignment first = remaining(12, 4) waits for that value and stores 8. The next call stores 3 in second. Neither call prints.

    The final statement prints 11. A statement after an executed return in the same call is not reached.

    Read the complete extra-call pair and scope

    Return values survive their calls. A function returns a local calculation that the caller stores.

    Python 3: def extra(a,b): result=a+b; return result. Then first=extra(2,5); second=extra(4,1); print(first,second).

    Keep the scripts separate. Main remaining returns 8 and 3 to first/second, then prints 11. The pictured extra returns 7 and 5, then prints 7 5. W2 stores remaining results 5,0,5 in a/b/c. Each script starts from its own complete definition and calls. In the picture return passes 7 back; the caller’s first=extra(...) assignment binds first. A later local result does not overwrite that stored integer.

    This lesson uses immutable numbers; shared mutable objects need separate reference reasoning.

    Main lesson · Section 7

    Find print used where the caller needs a return

    None is neither a measured zero nor the displayed number.

    Read the complete faulty print-only function

    def remaining(capacity, used):
    spaces = capacity - used
    print(spaces)

answer = remaining(12, 4)
print(answer)

    Trace display 8 then stored None

    This faulty version displays 8 and then None. It reaches the end of its body without a return statement, so the call returns None. Printing 8 inside the function does not make 8 its return value. None is not zero.

    Trying answer + 1 raises TypeError in this example.

    Repair return and keep the caller’s print

    Replace print(spaces) inside the function with return spaces. Keep print(answer) in the caller. The repaired script prints 8 once, and the caller can calculate answer + 1.

    Test the stored value as well as what appears on screen.

    Explain the failed addition and corrected result

    • Use the faulty printing version with answer = remaining(11, 2). State the displayed number and the value stored in answer. Explain why print(answer + 1) fails, then repair the function and predict the repaired output.
