Main lesson · Section 3

Calculate every matched residual before averaging

Zero mean signed error can conceal several wrong predictions.

Complete three-case cancellation example

Observed heights [4, 7, 9] cm and predictions [5, 6, 9] cm give residuals [-1, 1, 0] cm. The first prediction is too high, the second too low and the third exact. Mean signed residual is zero, yet two predictions are wrong.

Opposite errors can cancel.

Optional original calculation script

observed = [4, 7, 9]
predicted = [5, 6, 9]
residuals = [y - p for y, p in zip(observed, predicted)]
print(residuals)
print(sum(residuals) / len(residuals))
# Output: [-1, 1, 0] and 0.0.
# Opposite signed errors can cancel.

Trace and state matching assumptions

Trace the calculation on paper before running this optional Python check. Use the stated fictional inputs and compare intermediate values. The code checks this example; your independent workbook case uses different evidence.

The original zip-based example assumes nonempty lists with equal lengths, matching case order and consistent height units. zip alone does not verify those conditions and silently truncates unequal lists. An exact residual0establishes equality only for that recorded pair, not a reliable model. Mean signed residual0can arise through cancellation; retain per-case magnitudes and sample size.

Optional complete matched-record summary program

import math


def summarize(records):
    if not records:
        raise ValueError('No observed residual mean without matched records')
    if len({item_id for item_id, observed, predicted in records}) != len(records):
        raise ValueError('Repeated case ID')
    residuals = []
    for item_id, observed, predicted in records:
        for value in (observed, predicted):
            if type(value) not in (int, float) or not math.isfinite(value) or value < 0:
                raise ValueError('Need finite nonnegative heights in the same declared unit')
        residuals.append(observed - predicted)
    return residuals, sum(residuals) / len(residuals), sum(abs(r) for r in residuals) / len(residuals)


# Matched case ID, observed day-7 height cm, supplied predicted height cm.
records = [('R1', 3, 4), ('R2', 5, 4), ('R3', 6, 8),
           ('R4', 10, 8), ('R5', 8, 12), ('R6', 16, 12)]
print(summarize(records))
# Semantic pairing, measurement truth and units still require source checking.
