Main lesson · Section 2

Three trays, three positions, two repeated values

Equal values in different positions remain separate list items.

Read the ordered input

A fictional supply shelf has three trays with counts 4, 7 and 4 in that order. Store them as counts = [4, 7, 4]. Square brackets enclose the list and commas separate its items.

The order matters: the first and third trays contain equal values but occupy different positions.

Distinguish length, nonnegative index and final-item -1

Python counts positions from zero: counts[0] is first, counts[1] second and counts[2] third. len(counts) is 3 for three items; it is not the last nonnegative index. Start with nonnegative indexing, then use this lesson’s pictured extension: index -1 reads the final item of a nonempty list. Both positive and negative item access require an existing position; an empty list has no last item.

    Main lesson · Section 7

    Find the nonexistent index or value used as a position

    A failed access stops later statements in that run.

    Read the deliberate IndexError example

    counts = [4, 7, 4]
print(counts[3])

    Explain the last valid position and empty boundary

    This deliberately faulty script raises IndexError. The list has three items, but its nonnegative indices are 0, 1 and 2. Replace 3 with 2 to read the third item, which is 4.

    For any nonempty list, len(counts) - 1 identifies the last item using a nonnegative index. An empty list has no valid item index.

    Compare looping through values versus indices

    Avoid confusing values with positions: for count in counts followed by counts[count] would try indices 4, 7 and 4 in this example. If you need both, use for index in range(len(counts)) and read counts[index].

    If you only need a total, looping directly through values is simpler.
