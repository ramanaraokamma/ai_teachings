Notice the evidence

Investigate the supplied Activation functions case. Separate observations, given facts and assumptions before choosing an explanation.

First compute an affine score z = w dot x + b. An activation then returns a = f(z). In a network this value may become an input to another layer; it is not automatically a class prediction.

We will compare three functions using the same incoming scores so that only the activation changes.

Identity returns z unchanged. ReLU, pronounced ree-loo, returns the larger of zero and z. Thus ReLU(-2) = 0, ReLU(0) = 0 and ReLU(2) = 2. Positive scores keep their magnitude; ReLU does not turn every positive value into 1.

See how it works

Follow the mechanism for Activation functions. Connect each labelled input, deciding step and result.

Sigmoid is 1 / (1 + exp(-z)). Here exp(t) means e raised to power t, where e is approximately 2.718. A calculator or the supplied Python code can evaluate it; no calculus is required this week.

For z = -2, 0 and 2, sigmoid outputs are approximately 0.1192, 0.5 and 0.8808.

For every finite mathematical input, sigmoid is strictly between 0 and 1, though computer rounding can produce an endpoint for extreme scores.

Negative inputs produce values below 0.5, zero gives 0.5, and positive inputs give values above 0.5. A class rule still needs to be stated: if class 1 means sigmoid(z) >= 0.5, these three predictions are 0, 1 and 1.

from math import exp

def sigmoid(z):
    if z >= 0:
        return 1 / (1 + exp(-z))
    e = exp(z)
    return e / (1 + e)

for z in [-2, 0, 2]:
    print(z, max(0, z), round(sigmoid(z), 4))

The two algebraically equivalent branches avoid taking exp of a large positive number. A value within [0, 1] is not automatically a reliable probability: its interpretation depends on the fitted task and evaluation evidence.

Why the result follows

Find and repair a mistake

Find the unsupported step in the Activation functions claim and explain a repair using the supplied evidence.

Check the claim against the facts

An affine function has one fixed slope. ReLU has slope zero on the negative side and slope one on the positive side, so no single straight line fits the whole function.

For a concrete check, inputs -2, 0, 2 give outputs 0, 0, 2. The average of the endpoint outputs is 1, but the output at the midpoint 0 is 0. This differs from an affine function, which preserves midpoints.

Check the claim against the facts

For a one-input chain with identity between stages, h = 2x + 1 followed by y = 3h - 2 collapses to y = 6x + 1. Insert ReLU instead: h = max(0, 2x + 1), y = 3h - 2.

At x = -1, the identity chain gives -5 while the ReLU chain gives -2. At x = 1, both give 7. The nonlinear step can change the overall family of functions.

Locate the earliest unsupported step

Compare ReLU at inputs -2, 0, 2. Give the average of the two endpoint outputs and the output at the midpoint; explain what this shows.

Student lesson · 12 of 18

Show what you know

Use a genuinely new case for independent evidence. Previously discussed examples remain practice; use the separately named independent case before feedback.

A nonlinear activation allows a network to represent relationships that a chain of affine operations alone cannot express. It does not guarantee that training will find a useful model or that more layers will help.

ReLU can erase differences between negative scores; sigmoid can compress very large scores into nearly identical values. The architecture, data and training procedure still matter.
