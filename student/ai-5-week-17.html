    Pseudorandom sequence and explicit separation

    A pseudorandom generator produces a sequence determined by its state. In the same Python setup, recreating a local generator with the same seed and making the same calls reproduces the sequence below.

    Saving the generated values also removes ambiguity about which draw became which parameter.

    The code contains two separate demonstrations. Four uniform random draws from a local seeded generator show repeatability of that sequence in the same setup with the same calls. The three scalar training runs instead start at the explicit values 0, 1, 3; they do not use those draws. The uniform range−1to1is a classroom illustration, not an initialization recommendation.

    Identical seed plus different draw order can assign different values to weights. Save actual values, their names/order and the environment as well as the seed.

    The four random numbers illustrate a saved initialisation sequence; they are not used in the three separate scalar training runs.

    The range [-1, 1] is a classroom choice, not a general recommendation for network initialisation. An extra random draw before assigning weights shifts which value is used, even if the seed stays the same.

    from random import Random

def initial_values(seed):
    rng = Random(seed)
    return [rng.uniform(-1.0, 1.0) for _ in range(4)]

def train(v):
    states = [v]
    for _ in range(2):
        v = v - 0.1 * 5 * (v - 2)
        states.append(v)
    return states

second = initial_values(17)

      Main lesson · Section 7

      Repair seed-only records and identical-unit assumptions

      A controlled starting-value comparison is not a guarantee for every architecture.

      Complete two-unit gradients,symmetry and all-zero limitation

      For the two-unit example, y = a ReLU(ux) + b ReLU(vx). At x = 1, u = v = a = b = 1, output is 2 and target is 1. Because both ReLUs are in their positive region, changing any one parameter slightly changes y at rate 1.

      Squared-error gradient is twice residual times that sensitivity, so each gradient is 2. Students can check it with the symmetric numerical probe from Week 10.

      With identical initial weights, identical data and deterministic symmetric updates, these units remain copies and cannot learn distinct roles through those updates alone. Different hidden weights can break the symmetry.

      For example, u = 1 and v = -1 give hidden activations [1, 0] at x = 1 and [0, 1] at x = -1. This demonstrates different responses, not a guarantee of successful training.

      Zero is not always an invalid start: v = 0 worked in our single trained-output-weight model.

      But setting all four weights to zero in the two-unit product model leaves every single-coordinate loss probe unchanged, because each path still contains a zero factor.

      Do not generalise the success of one scalar start to every architecture.

      from random import Random

def assigned_weights(seed, preview=False):
    rng = Random(seed)
    if preview:
        rng.uniform(-1, 1)  # Same generator call consumes the first draw.
    return [rng.uniform(-1, 1) for _ in range(4)]

normal = assigned_weights(17)
replay = assigned_weights(17)
shifted = assigned_weights(17, preview=True)
print('identical calls repeat', normal == replay)
print('extra preview keeps assigned weights equal', normal == shifted)
print('normal assigned values', normal)
print('shifted assigned values', shifted)

      Complete four-parameter symmetry experiment

      # Separate two-unit symmetry example, not the scalar-v training experiment.
# Parameters are in fixed order [u, v, a, b]. No random initialization is used here.
def output(params, x):
    u, v, a, b = params
    return a * max(0, u*x) + b * max(0, v*x)

def update(params, x, target, rate):
    u, v, a, b = params
    z1, z2 = u*x, v*x
    h1, h2 = max(0,z1), max(0,z2)
    residual = a*h1 + b*h2 - target
    # ReLU derivative convention at zero is 0 for this teaching program.
    gradients = [2*residual*a*x*(z1>0), 2*residual*b*x*(z2>0),
                 2*residual*h1, 2*residual*h2]
    new = [old-rate*g for old,g in zip(params,gradients)]
    return gradients, new, (output(new,x)-target)**2

old = [1.,1.,1.,1.]
gradients, new, loss = update(old, 1, 1, .1)
print('old [u,v,a,b]', old, 'output', output(old,1))
print('gradients', gradients)
print('new [u,v,a,b]', new)
print('new output/loss', round(output(new,1),6), round(loss,6))
print('identical units remain identical', new[0]==new[1] and new[2]==new[3])
print('all-zero start gradients', update([0.,0.,0.,0.],1,1,.1)[0])
print('hidden activations u1/v-1 at x1', [max(0,u*1) for u in [1,-1]])
print('hidden activations u1/v-1 at x-1', [max(0,u*(-1)) for u in [1,-1]])
