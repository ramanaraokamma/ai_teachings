Matrix purpose and new fictional evaluation source

A confusion matrix shows which labels a classifier mixes up. It counts examples after predictions are made; it does not fit or repair the classifier. Week 13 had reference/prediction pairs clear/clear, blocked/blocked, clear/blocked. A labelled table can preserve the type of that error as well as the total score.

Read row/column totals and alternative error pattern

Row totals are 3 reference-clear and 5 reference-blocked. Column totals are 4 predicted-clear and 4 predicted-blocked. All four cells sum to 8. Accuracy is the diagonal total divided by the total: 5/8, or 62.5 percent. The Week 13 three-record matrix was [[1,1],[0,1]] in this same axis order, giving 2/3.

Another classifier on these same eight reference-labelled records could have matrix [[3,0],[3,2]]. It also gets 5/8 correct, but has zero false positives and three false negatives.

Our worked classifier has one false positive and two false negatives. Equal accuracy does not settle which error pattern is preferable; consider the task and evidence before choosing.

def build_counts(pairs, labels):
    if len(labels) != 2 or len(set(labels)) != 2:
        raise ValueError('Declare exactly two distinct labels in axis order')
    ids = [item_id for item_id, actual, predicted in pairs]
    if len(ids) != len(set(ids)):
        raise ValueError('Repeated evaluation ID: review the source')
    index = {label: i for i, label in enumerate(labels)}
    counts = [[0, 0], [0, 0]]
    for item_id, actual, predicted in pairs:
        if actual not in index or predicted not in index:
            raise ValueError('Missing, unresolved or unsupported label')
        counts[index[actual]][index[predicted]] += 1
    total = sum(sum(row) for row in counts)
    correct = counts[0][0] + counts[1][1]
    return counts, correct, total


# The complete printed C01–C20 fixture, with reference first in every pair.
pairs = [(f'C{i:02}', 'spotted', 'spotted') for i in range(1, 5)]

pairs += [(f'C{i:02}', 'healthy', 'spotted') for i in range(6, 9)]
pairs += [(f'C{i:02}', 'healthy', 'healthy') for i in range(9, 21)]
labels = ['spotted', 'healthy']
counts, correct, total = build_counts(pairs, labels)

01. Confusion Matrix: the case

Read the confusion matrix as four distinct stories about a plant decision. Supplied facts: Positive means spotted. Toy results: TP=4, FN=1, FP=3, TN=12. Rows are actual spotted/healthy; columns predicted spotted/healthy.

All inputs and outcomes in this worked example are invented classroom data; no real model run is claimed.

Point to the given fact that matters most. Explain why it matters.

02. Follow the deciding steps

Fill actual spotted row: Actual spotted: [4, 1]. Four caught; one missed. → Fill actual healthy row: Actual healthy: [3, 12].

Three false alarms; twelve correctly clear. → Compute accuracy: Correct=4+12=16 of total 20, giving80%.

Point to each numbered stage and explain which recorded input it uses.

03. Positive means spotted

Positive means spotted. actual spotted: predicted spotted = 4, predicted healthy = 1. actual healthy: predicted spotted = 3, predicted healthy = 12.

Read the labels and values. Explain the relationship the model shows.

04. Change one thing. Trace what follows.

Original case: Correct=4+12=16 of total 20, giving80%. Changed condition: A review corrects one missed spotted leaf, moving it from FN to TP. Expected result: Counts become TP 5, FN 0, FP 3, TN 12; accuracy is 17/20=85%.

Reason: One decision becomes correct while the total number of evaluated leaves remains20.

Predict before checking the worked changed-case result. Name what changed and what the supplied facts allow you to conclude.

05. Connect the explanation to its limit

Read the picture in order. Correct=4+12=16 of total 20, giving80%. The arrows show which recorded input or intermediate result each decision uses.

Explain the deciding step aloud before checking the changed case; pointing to the final answer alone does not show how it follows. Limit: The matrix depends on positive-class definition and reference labels.

Accuracy alone hides the difference between misses and false alarms.

Explain the case, then point to a limit on the claim.
