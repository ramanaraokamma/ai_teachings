Main lesson · Section 2

Judge augmentation by the declared target rule

For this arithmetic task,row and column swaps have different consequences.

Complete target and three transformed cases

Return to the binary image task: class 1 means the left column sum is strictly larger than the right column sum; equal sums belong to class 0. Let d be left sum minus right sum.

An augmentation is useful only under a stated task and transformation rule. More image files do not automatically mean more independent evidence.

Operation on rows [1, 0] and [0, 0]Result rowsdClass
Original[1, 0] and [0, 0]11
Swap top and bottom rows[0, 0] and [1, 0]11
Swap left and right columns[0, 1] and [0, 0]-10

Prove the label rule and name its scope

Swapping rows preserves each column sum, so it preserves this task label for every valid image. Swapping columns changes d to -d. For nonzero d the class changes; for d = 0 it stays class 0.

Blindly copying the original label after every flip would create incorrect training targets.

A transformation may be valid for one task and invalid for another. A crop can remove the evidence needed for a label.

Choose allowed transformations using the task definition and training evidence, document the assumptions, and evaluate the choice on validation data.

    Known-rule proof and experiment limits

    The label function is the supplied mathematical task, not a tool for inferring unknown real-world labels. Row swapping preserves each column sum. Column swapping negates d, so it changes the binary class only when d is nonzero. The original functions create new lists and leave their input unchanged.

    Audit lineage,duplicate pixels and the meaning of unseen sources

    Each audit catches a different failure;metadata alone does not verify real independence.

    Complete previous-week relation and split-repair explanation

    Week 23 used deliberately constructed toy images. Its validation E is exactly a row-swapped version of training A, and F is a row-swapped version of C.

    They had different pixel arrays, but the transformation relation means they are a weak independence test for an experiment that trains on row-swapped variants.

    If those variants are added, they become exact training-validation duplicates. Preserve the original narrow claim and design a new grouped split for the augmentation experiment.

    Source groups should match the evaluation question. If the goal is generalisation to new objects or people, several photographs of the same object or person may need one group even when they have different original file IDs.

    A lineage audit catches recorded relationships; an exact-pixel audit catches duplicates with inconsistent IDs. Neither audit alone proves that all dependence has been removed.

    When a leak is discovered after validation has influenced choices, repair the split and rerun training and selection.

    Do not merely rename or remove the overlapping files and keep claiming the old score evaluates the repaired experiment. Final data that influenced decisions is no longer reserved.

    Complete runnable label and overlap audit

    # Complete fictional provenance audit. No model is trained and no new score is claimed.
from copy import deepcopy
from itertools import product

def difference(x):
    return x[0][0]+x[1][0]-x[0][1]-x[1][1]
def label(x):
    return int(difference(x)>0)
def swap_rows(x):
    return [x[1][:],x[0][:]]
def swap_columns(x):
    return [row[::-1] for row in x]

# Every binary 2x2 pattern checks the known mathematical rule, not unknown real labels.
for bits in product([0,1],repeat=4):
    x=[list(bits[:2]),list(bits[2:])]
    assert label(swap_rows(x))==label(x)
    assert difference(swap_columns(x))==-difference(x)
    expected=0 if difference(x)==0 else 1-label(x)
    assert label(swap_columns(x))==expected
print('all 16 binary patterns: row swaps preserve labels; column swaps require the declared rule')

sources = {
    'P': ([[1,0],[0,0]], 'training'),
    'Q': ([[0,1],[0,0]], 'training'),
    'R': ([[1,0],[1,0]], 'validation'),
    'S': ([[0,1],[0,1]], 'final'),
    'T': ([[1,1],[0,0]], 'final'),
}
inventory=[]
for group,(image,split) in sources.items():
    for transform,pixels in [('original',deepcopy(image)),('row_swap',swap_rows(image))]:
        inventory.append({'id':group+'-'+transform,'source':group,'parent':None if transform=='original' else group+'-original',
                          'split':split,'transform':transform,'pixels':pixels,'label':label(pixels)})
retained=[r for r in inventory if r['split']=='training' or r['transform']=='original']

def audit(records):
    groups={};pixels={}
    for r in records:
        groups.setdefault(r['source'],set()).add(r['split'])
        key=tuple(tuple(row) for row in r['pixels'])
        pixels.setdefault(key,[]).append((r['id'],r['split']))
    shared_groups={g:sorted(s) for g,s in groups.items() if len(s)>1}
    duplicate_pixels=[pairs for pairs in pixels.values() if len({split for _,split in pairs})>1]
    return shared_groups,duplicate_pixels

for split in ['training','validation','final']:
    part=[r for r in retained if r['split']==split]
    print(split,'groups / retained records',len({r['source'] for r in part}),len(part))
print('retained / excluded',len(retained),len(inventory)-len(retained))
print('clean recorded-group / exact-pixel overlaps',audit(retained))

bad_group=deepcopy(retained)
next(r for r in bad_group if r['id']=='P-row_swap')['split']='validation'
print('new filename does not repair shared source:',audit(bad_group)[0])

alias=deepcopy(next(r for r in retained if r['id']=='P-row_swap'))
alias.update(id='claimed-U-original',source='claimed-U',parent=None,split='validation',transform='original')
print('different claimed source, same pixels:',audit(retained+[alias]))
print('Audit only: exact pixels do not prove real-object identity; missing provenance still needs review.')
print('Any affected fitting/selection must be rerun after a justified split repair; no repaired score is supplied.')
