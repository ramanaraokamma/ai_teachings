Separate learned patterns from inspectable records

What memory and retrieval mean

Model memory is an informal name for patterns encoded in learned parameters. It is not a document catalogue that guarantees the exact origin, date or wording of an answer. Retrieval selects stored records for a query; a later generator may use those records to compose an answer. Retrieval makes a source inspectable, but selection, freshness, permissions and correct use still need checking.

This lesson uses supplied paper records, not a live model or search engine.

Understand the retrieval operation

Retrieval returns stored records selected for a query. An index is a searchable representation of a versioned corpus; generated wording is a later operation.

Begin by writing the question the procedure is intended to answer. Identify the information already supplied, the information it will produce and the information still missing.

These are constructed classroom examples; they do not require live accounts, private records or an external service. Do not treat a plausible explanation as a measured outcome.

Main lesson · Section 3

Trace corpus → eligible index → passage → answer

Document identity and version must survive the pipeline.

Set IDs, versions and permissions

Assign stable document IDs, versions and permitted access before indexing. Retrieve only authorised records. Preserve source references and define behaviour when a document is missing, outdated or access-restricted.

Apply the full source-selection contract

Classroom contract: the corpus is the collection of available records; the index is its searchable representation, which may lag behind it. Match document ID, version, access eligibility and requested time before using a retrieved passage. A high similarity score is a relevance clue, not permission or proof of freshness. If a current approved source is unavailable, state that the current fact cannot be verified.

Do not substitute an old generated answer.

Preserve missing-input limits

Before applying the procedure, write its units, denominator or decision boundary where relevant. A partner should be able to repeat each step using the same inputs.

If a required input is absent or violates the stated contract, record that condition explicitly instead of quietly replacing it with a convenient value.
