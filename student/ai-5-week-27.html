    Complete dot-product and cosine derivation

    Multiply matching components and add to obtain the dot product. Cosine similarity equals dot(Q, candidate) divided by (length(Q) times length(candidate)). Higher cosine means a closer direction.

    For A, the dot product is 3 times 6 + 4 times 8 = 50, so cosine = 50 / (5 times 10) = 1. For B it is 9 / 15 = 0.6; for C it is -25 / 25 = -1.

def unit(v):

    Main lesson · Section 7

    Declare what normalization discards and how zero is handled

    A real zero input can be meaningful even when this directional comparison is unavailable.

    Complete magnitude,zero and scaling explanation

    Suppose [3, 4] records counts of two event types, while [6, 8] records twice as many of each. Both have the same proportions and direction, but totals are 7 and 14. Normalisation makes their vectors identical.

    That may suit a question about proportions, but it removes information needed to compare total activity. For learned embeddings, the usefulness of length must be tested for the task.

    The zero vector [0, 0] has no direction, so its cosine is undefined. Do not silently assign zero similarity: zero cosine already means perpendicular nonzero vectors.

    This lesson rejects a zero query and excludes zero candidates with an explicit report. If no valid candidates remain, return no comparison. PAD entries stay excluded by the mask; a real zero input needs its own policy.

    Positive scaling preserves cosine: Q and 2 times Q have the same direction. Negative scaling reverses direction; Q and -Q have cosine -1.

    Candidate labels, self-exclusion and a stated floating-point tie tolerance are still required when retrieving neighbours.

# Complete raw/unit comparison and explicit zero-candidate policy.
from math import isfinite

def distance2(a,b):
    if not a or len(a)!=len(b):
        raise ValueError('Need equal nonempty dimensions')
    return sum((x-y)**2 for x,y in zip(a,b))

def cosine_rank(query,candidates,tolerance=1e-9):
    unit(query)  # Reject an empty or zero query, not an invented zero cosine.
    if not isfinite(tolerance) or tolerance<0:
        raise ValueError('Need nonnegative finite tie tolerance')
    scores={};excluded=[]
    for name,vector in candidates.items():
        if not vector or len(vector)!=len(query):
            raise ValueError('Candidate dimensions must match query')
        if all(x==0 for x in vector):
            excluded.append(name)
        else:
            scores[name]=cosine(query,vector)
    if not scores:
        return [],excluded,scores  # Explicit no-comparison result.
    best=max(scores.values())
    return sorted(n for n,c in scores.items() if abs(c-best)<=tolerance),excluded,scores
