Student lesson · 2 of 17

Notice the evidence

Use fictional robot event logs whose symbols are GO, TURN and STOP. The task asks whether the final real event is STOP. This is a representation exercise, not a claim that an event log proves a robot is safe. GO then STOP and STOP then GO contain the same symbols but have different final events.

LogCounts in GO TURN STOP orderFinal eventTask answer
GO STOP[1, 0, 1]STOPYes
STOP GO[1, 0, 1]GONo
GO TURN STOP[1, 1, 1]STOPYes

A count vector discards order, so no deterministic rule using only the first two count vectors can distinguish their answers. A sequence of IDs preserves order if we retain each position. Declare the vocabulary: PAD = 0, UNK = 1, GO = 2, TURN = 3 and STOP = 4. PAD is reserved for added storage positions; UNK represents a real but unrecognised symbol.

IDs are names, not measured amounts. STOP having ID 4 does not make it twice as much as GO with ID 2. Changing the vocabulary requires changing every consumer consistently. Do not interpret numerical distance between IDs as semantic similarity.

Student lesson · 3 of 17

See how it works

Store each log in four positions, padding on the right. A mask value 1 marks a real position and 0 marks padding. The encoder rejects empty logs, logs longer than four, and literal reserved markers. Other unrecognised symbols become UNK and still receive mask 1.

VOCAB = {"GO": 2, "TURN": 3, "STOP": 4}

def encode(events):
    if not 1 <= len(events) <= 4:
        raise ValueError("Need one to four real events")
    if any(e in ("PAD", "UNK") for e in events):
        raise ValueError("Reserved markers are not events")
    ids = [VOCAB.get(e, 1) for e in events]
    n = len(ids)
    return ids + [0] * (4 - n), [1] * n + [0] * (4 - n)

assert encode(["GO", "STOP"]) == ([2, 4, 0, 0], [1, 1, 0, 0])
assert encode(["WAIT", "STOP"]) == ([1, 4, 0, 0], [1, 1, 0, 0])
assert encode(["STOP", "GO"]) == ([4, 2, 0, 0], [1, 1, 0, 0])

The code assumes a list of symbol strings and uses exact spelling. It does not fit a vocabulary from data. If a future project fits vocabulary choices or frequency cutoffs, derive those choices from training data and apply the saved encoding consistently to validation and final cases.

Why this result follows

Sequence values and sequence length are separate information. Padding fills unused storage positions so arrays can share a size; a mask marks which positions are real. A real sensor reading can be zero, just like a padding value. Keep the length or mask rather than inferring presence from the number alone. Token IDs are identifiers, not measured magnitudes.

What this example does not establish

Token padding rules need not apply to sensor values. Document sequence lengths, vocabulary and unknown-token handling.

Student lesson · 7 of 17

Find and repair a mistake

A mask must affect a calculation to protect it from padding. Suppose real sensor values are [2, 4], stored as [2, 4, 0, 0] with mask [1, 1, 0, 0]. The masked mean is (2 + 4) / 2 = 3. Averaging all four slots gives 1.5. Unlike arbitrary token IDs, these sensor values are measurements for which a mean is meaningful.

Measured zero must remain real: values [0, 4, 0, 0] with mask [1, 1, 0, 0] have mean 2. Removing every zero would incorrectly give 4. The mask distinguishes a measured zero from a storage placeholder. An all-zero mask has no real values; reject it or follow an explicitly defined empty-input policy instead of dividing by zero.

Storing ordered IDs makes order available but does not guarantee a later model uses it. A computation that sums token counts or averages position-independent vectors can lose order again. Trace what the whole procedure reads, not just what the input format could preserve.

Show what you know

WAIT STOP and PAUSE STOP both become [1, 4, 0, 0] with the same mask. UNK retains a real position but loses the identity of the unrecognised symbol. The final-event task can still answer Yes for both because the last real ID is STOP. A final real UNK would require an unknown result or another documented policy when the intended event cannot be determined.

The full log ends in STOP, while the retained prefix ends in TURN. Truncation changes the evidence needed for this task. Save the original length and any truncation policy in a real experiment, and test the consequences.
