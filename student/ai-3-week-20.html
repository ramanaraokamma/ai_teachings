Main lesson · Section 2

Separate current fields, summaries and learned parameters

Remembered wording is not automatically current or verified.

Understand application state

Conversation state is an application record used across turns, such as a selected book or current topic. It is not evidence that a model permanently learned that preference. A summary is a derived copy and can become stale when a user corrects a value. Keep only fields needed for the task, attach their source turn, and define when they are replaced or cleared.

Product policies differ; this lesson uses the explicit toy session policy below.

Conversation state stores facts or prior interactions for later use. It needs scope, provenance, correction and retention rules rather than indefinite accumulation.

Use supplied fictional records

Begin by writing the question the procedure is intended to answer. Identify the information already supplied, the information it will produce and the information still missing.

These are constructed classroom examples; they do not require live accounts, private records or an external service. Do not treat a plausible explanation as a measured outcome.

Main lesson · Section 3

Apply a visible state-transition contract

Current value and audit history have different roles.

Read the complete toy lifetime policy

Toy session policy: keep the one current approved selection only during this session. A correction replaces its active value; retain a minimal old→new audit event only until session end. A cached summary carrying the old selection must be refreshed or invalidated before use. On exit, clear the active selection, summary and session audit. A new session begins without a selection and asks for one.

Do not retain unrelated private text. This classroom contract does not claim to erase model training data or external logs in a real service.

Connect room state and correction

This classroom assistant keeps an approved room ID only for the current session. A later correction replaces the active value but retains an audit event until session end.

Do not persist private text merely because it appeared in conversation.

Respect scope and missing values

Before applying the procedure, write its units, denominator or decision boundary where relevant. A partner should be able to repeat each step using the same inputs.

If a required input is absent or violates the stated contract, record that condition explicitly instead of quietly replacing it with a convenient value.
