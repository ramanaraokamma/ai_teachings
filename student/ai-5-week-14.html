Complete restricted-network experiment

Use the same restricted network h = ReLU(x), y = vh, with only v trained. Keep the fictional training pairs (1, 2) and (2, 4), start v = 0, and use one full-data batch per update.

Compare rates 0.05, 0.2, 0.3, 0.4 and 0.5 for exactly four updates each. Restart at zero for every run.

The training objective is ordinary MSE: L(v) = 2.5 times (v - 2) squared. Its gradient is 5 times (v - 2). A step is new v = v - rate times 5 times (v - 2).

This small quadratic lets us explain each result rather than treating the rate as a magic setting.

    A sign-changing distance can shrink,stay the same or grow.

    Derive the signed-distance recurrence

    Write d = v - 2, the signed distance from this objective minimum. Substituting the update gives new d = (1 - 5 times rate) times old d. At rate 0.05 the factor is 0.75: distance shrinks without changing sign.

    At rate 0.3 it is -0.5: distance changes sign and halves. Both can reduce loss.

    Complete runnable rate experiment

    def run(rate, updates=4):
    v = 0.0
    history = [v]
    for _ in range(updates):
        gradient = 5 * (v - 2)
        v = v - rate * gradient
        history.append(v)
    losses = [2.5 * (value - 2) ** 2 for value in history]
    return history, losses

for rate in [0.05, 0.2, 0.3, 0.4, 0.5]:
    values, losses = run(rate)
    print(rate, values, losses)

    Main lesson · Section 7

    Repair universal rate rules and changed-objective comparisons

    A rate is meaningful together with the gradient scale and update definition.

    Exact quadratic bound and mean-versus-sum scaling

    For a nonzero starting distance, loss strictly decreases on each step of this quadratic when the absolute value of 1 - 5 times rate is below 1. For positive rates this means 0 < rate < 0.4. At 0 the model does not move.

    At 0.4 it oscillates with unchanged loss. Above 0.4 its distance grows. These bounds belong to this model and objective, not to neural networks generally.

    If we switch from mean squared error to the sum over the same two examples, the gradient doubles from 5(v - 2) to 10(v - 2). Keeping the old rate changes the update. To reproduce the original steps, halve the rate.

    Likewise, rescaling features can change gradient magnitudes. Record the loss and units alongside the rate.

    Find the sum-objective equivalent rate

    • Replace MSE by the sum of squared errors on the two training pairs. Which rate reproduces the MSE run at rate 0.3? Explain using gradients.
