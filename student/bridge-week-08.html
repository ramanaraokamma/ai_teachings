Main lesson · Section 2

Reuse a written remaining-space procedure

A function name does not prove its body uses the arguments correctly.

Read the capacity-minus-used task

A fictional supply cupboard records capacity and the number of occupied spaces. The remaining-space calculation is capacity minus used.

Instead of copying the same instructions for every cupboard, define one function and call it with different values. A function makes a procedure reusable; its name alone does not guarantee that its instructions are correct.

State the input assumptions and return preview

The main remaining-space example assumes nonnegative integer counts with used<=capacity; it does not validate them. Its function prints a result. A short return-value preview below prepares you to read the selected transfer script: return hands a value back to the caller, whose print displays it. Week 9 will develop returned values and local state further.

    Trace the same function with reversed arguments

    Position changes the binding and therefore ordered subtraction.

    Read complete pictured calls and scope

    Match arguments to parameters. A function prints the difference between capacity and reserved spaces.

    Python 3: def show_free(capacity,reserved): print(capacity-reserved). Calls: show_free(11,3); show_free(3,11).

    Separate the contracts. Main show_remaining assumes used<=capacity, so reversed (4,12) is outside its valid remaining-space domain even though arithmetic prints -8. The pictured show_free pair deliberately demonstrates subtraction order: 11-3=8 and 3-11=-8. A negative arithmetic result is not a valid free-space count under the main contract. Removing calls leaves definitions but no printed output.

    Trace definition and two parameter bindings

    Positional arguments match parameter names in order. A function definition is not an execution of its body; separate calls supply separate input values.

    Execution eventWhat happens

    Find constants that ignore the function’s arguments

    A first example can pass by accident while reuse fails.

    Read the complete faulty body

    def show_remaining(capacity, used):
    remaining = 12 - 4
    print(remaining)

show_remaining(12, 4)
show_remaining(10, 7)

    Compare actual repeated 8 with expected new inputs

    This faulty function prints 8 twice. Its fixed numbers ignore the arguments. Replace 12 - 4 with capacity - used, then rerun both calls.

    Testing only the first call would miss the bug because its expected answer happens to be 8.

    Distinguish a missing argument from no call

    For this two-parameter definition, show_remaining(12) raises TypeError because an argument is missing. Correct the call to supply both values.

    Naming a function without calling it does not execute the body: the parentheses in show_remaining(12, 4) are part of the call.

    Repair and choose a regression call

    • The faulty body calculates 12 - 4 regardless of the call. State the output and expected output for show_remaining(11, 2). Repair the expression and name an earlier call to rerun.
