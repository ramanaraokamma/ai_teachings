Start with the research problem

Power is the probability that a specified test rejects under a specified alternative effect and design. A finite set of simulations can estimate that probability, with simulation uncertainty. This lesson supplies counts; it does not run those simulations. Larger sample size may improve detection under the stated assumptions while costing more, but no universal sample-size rule follows.

Keep the effect, variability, unit independence, test and resource model visible.

Original concept explanation

Power concerns detecting a declared effect under a specified model and test. Planning depends on effect size, variability, unit independence and budget.

    Separate pictured inputs and complete explanation

    A simulated detection-and-resource trade-off. A fictional simulation repeats a study under the same assumed alternative effect, using two independent-unit sample sizes.

    There are 100 simulation trials per design. At n=20, 60 detect the specified effect; at n=40, 80 detect it. Each independent unit costs 2 resource units. Same test and effect assumptions are used.

    The separate picture uses one hundred stipulated alternative trials per design, with sixty detections at n = 20 and eighty at n = 40. Its unit cost is two resource units, unlike the main example’s three credits. Estimated detection frequencies are 60% and 80%; per-study costs are forty and eighty resource units. The extra forty resource units accompany a twenty-percentage-point observed difference.

    Neither is a measured effect on real pupils. Changing the assumed effect or variability may change power even at the same sample sizes, but no replacement detection counts are supplied. Null false-positive error needs separate null trials or appropriate theory.

    Power estimates do not repair biased sampling or establish the probability a particular hypothesis is true.

    A useful check asks what would make the reasoning fail. Distinguish a failure to execute the declared procedure from a weakness in the procedure itself.

Compare with the separate picture’s 60/100 and 80/100 at unit cost two. Distinguish the per-study budget from hypothetical total work across one hundred trials; no actual billing or compute use is measured.

      Record missing model details, null trials and uncertainty rather than inventing them. Keep the independent n = 30 versus n = 60 task for a first attempt.

    """Summarize stipulated alternative-model simulation counts; do not simulate trials."""
from fractions import Fraction

def summarize(detections,trials,n,cost_per_unit):
 if any(type(x) is not int for x in (detections,trials,n,cost_per_unit)) or trials<1 or n<1 or cost_per_unit<1 or not 0<=detections<=trials:
  raise ValueError('valid integer trial counts, sample size and positive unit cost required')
 return {'detection_fraction':Fraction(detections,trials),'per_study_cost':n*cost_per_unit,
         'stated_simulation_work_cost':trials*n*cost_per_unit}
main_small=summarize(62,100,20,3);main_large=summarize(83,100,40,3)
picture_small=summarize(60,100,20,2);picture_large=summarize(80,100,40,2)
assert main_small['per_study_cost']==60 and main_large['per_study_cost']==120
assert 100*(main_large['detection_fraction']-main_small['detection_fraction'])==21
assert picture_small['per_study_cost']==40 and picture_large['per_study_cost']==80
assert picture_large['detection_fraction']-picture_small['detection_fraction']==Fraction(1,5)
print('Main summaries:',main_small,main_large)
print('Separate picture summaries:',picture_small,picture_large)
print('Per-study cost differs from total hypothetical work across 100 simulation trials; the latter is arithmetic, not measured compute or billing.')
print('These are supplied finite-trial detection frequencies under a fixed alternative, not executed simulations, exact known power or guaranteed real-study success.')
print('No null trials are supplied: false-positive rate is unknown. Changed effect/variability requires new model-specific planning; no new detection frequency is invented.')
