The loop and the unshown-item problem

A feedback loop occurs when today’s recommendation changes what can be observed, and those observations influence tomorrow’s recommendation. Suppose a system displays only the item with the most clicks, breaking an initial tie by ID. The first choice can receive every display opportunity and collect more clicks, while an unshown item stays at zero. That zero is not a recorded dislike.

The complete two-book event contract

Use two fictional books A and B. Start with zero displays and zero clicks for each. One displayed slot counts as one exposure; a click is a separate event. In this explicitly invented simulation, an A display receives a click and a B display does not. These scripted events are teaching assumptions, not observations of real readers. Compare a click-count selection policy with a predeclared A,B,A exposure plan; keep the event assumption fixed.

Predict and run the complete simulation

def simulate(plan=None):
    exposures = {"A": 0, "B": 0}
    clicks = {"A": 0, "B": 0}
    scripted_click = {"A": True, "B": False}
    log = []
    for round_number in range(3):
        if plan is None:
            shown = sorted(clicks, key=lambda name: (-clicks[name], name))[0]
        else:
            shown = plan[round_number]
        exposures[shown] += 1
        clicked = scripted_click[shown]
        if clicked:
            clicks[shown] += 1
        log.append((round_number + 1, shown, clicked, exposures.copy(), clicks.copy()))
    return log, exposures, clicks
for label, plan in [("click-count policy", None), ("planned exposure", ["A", "B", "A"])]:
    log, exposures, clicks = simulate(plan)
    print(label)
    for event in log:
        print(event)
    print("displays", exposures, "clicks", clicks)

Explain selection, saved records and scripted evidence

simulate keeps display and click dictionaries separate. The sorting key uses negative clicks to place larger counts first, then ID for equal counts. A supplied plan overrides that selection order without changing the scripted per-book events. copy saves each round’s counts instead of letting later updates overwrite earlier log entries. The returned log records round, shown ID, click event, displays and clicks. No hidden reader preference is inferred or fitted.

Review · Earlier deterministic scoring-function implementation
def recommend(items, limit):
    best = None
    best_score = None
    for item in items:
        if item["minutes"] <= limit:
            score = 2 * item["fun"] + item["learning"]
            if (best is None or score > best_score
                or (score == best_score and item["name"] < best)):
                best = item["name"]
                best_score = score
    return best

items = [{"name": "B", "fun": 3, "learning": 2, "minutes": 10},
         {"name": "A", "fun": 2, "learning": 4, "minutes": 9}]
print(recommend(items, 10))

The function prints nothing; the caller prints A. best starts as None to mean no eligible option found. Python short-circuits or: when best is None, later comparisons in that condition need not run.

After selecting an item, best_score is numeric. An empty list or no eligible item returns None.

Write a trace table with item, eligible, score and best-so-far. In the worked list, B qualifies and scores 8, so B becomes the current best. A also qualifies and scores 8.

The scores tie, so the written alphabetical rule changes the best to A. Starting with A gives the same final answer. If no item qualifies, best stays None; do not invent a winner or quietly relax the limit.

Main lesson · Section 7

Raw clicks cannot reveal preferences independently of exposure

Separate observed rates, missing opportunities and interpretation.

Read the denominator and meaning limits

Report exposure counts with click counts. A click can reflect curiosity, position or a mistake, and a nonclick is not an explicit statement of dislike. A zero-click item with zero displays has no observed click rate;0/0 is unavailable. One nonclick after one display gives0/1 for that observation, not a reliable future preference estimate. A controlled exposure plan can broaden opportunities without proving satisfaction or a causal effect by itself.
