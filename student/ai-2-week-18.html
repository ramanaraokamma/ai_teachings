Each duration row is one fictional activity session. This contract checks only the minutes field: an exact integer 0–60 inclusive. A missing field or explicit None means unknown here.         accepted.append(value)
    else:
        rejected = rejected + 1
print(accepted)
print(rejected)

Explain get, append and the type-first condition

get reads the minutes field without raising an error when the key is absent. The word and short-circuits: Python checks the exact type first and only tests the numeric bounds if that check succeeds. Thus None and text never reach a numeric comparison. type(value) is int also rejects Boolean True and False; arithmetic compatibility is not the same as this declared input contract.

dict.get returns None when this key is absent. An explicit None also represents unknown in this dataset. append adds an item to the end of a list. The script prints [0, 12] and then 3.

The exact type check prevents comparing None or text with the numeric range.

Match each raw value to the contract

A recorded 0 says the measured duration was zero. A missing field says we do not have the duration. They are different statements. Trace each record with three columns: raw value, decision and reason.

Keep 0 and 12; reject the absent value, -1 and None. The accepted list therefore has two values and the rejection count is three. Do not turn an unknown value into a number just to make the calculation run.

accepted = []
review = []
for number, row in enumerate(rows, 1):

    if value is None:

    elif type(value) is not int:
