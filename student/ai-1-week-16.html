Main lesson · Section 7

Repeated agreement does not reveal a missing input

State a supported prediction or unresolved outcome without inventing a confidence percentage.

Inspect what identical model runs actually repeat

A deterministic model repeats the same prediction for the same input and settings. Ten identical runs do not give ten independent measurements of a smudged digit.

Several models can also share a feature gap, training examples or mistaken assumption. Agreement alone is not proof that the prediction is correct.

Use a precise, limited result statement

Keep the claim specific: tall under both listed heights, input still unclear, or no category until the measurement is checked. Do not attach a made-up confidence percentage.

Evidence about correctness and the meaning of confidence will be developed in Weeks 17 and 18.

Repair the repeated-run claim

  • CLAIM A A good system must always choose one label.

  • CLAIM B Not sure means the system failed completely.

A useful review record preserves the original evidence and can end unresolved.

Use the explicit review policy

Use a written review policy: if stated possible valid heights lead to different predictions, pause the single-category output and request a measurement check.

If a required input or its unit is missing, request that information. After the check, apply the model only to a supported valid input; otherwise retain an unresolved outcome.

Write the request and both endings

    Record unresolved evidence rather than repeating a failed request forever
