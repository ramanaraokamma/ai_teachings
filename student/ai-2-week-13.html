What a confusion matrix records

A confusion matrix shows which labels a classifier mixes up. It counts examples after predictions are made; it does not fit or repair the classifier.

Week 12 had reference/prediction pairs clear/clear, blocked/blocked, clear/blocked. A labelled table can preserve the type of that error as well as the total score.

The axis and positive-class convention

Use reference labels for rows and predicted labels for columns. On both axes the order is clear, then blocked. Declare blocked as the positive class and clear as negative.

Trace one record into one matrix cell

The code counts supplied outcomes; it does not train or repair a model.

Understand the tuple and lookup syntax

Read each tuple as (ID, reference, prediction). enumerate(labels) gives clear position0 and blocked position1; the dictionary comprehension builds those two lookups. counts starts as two rows of two zeros. The first lookup chooses the reference row and the second chooses the prediction column. +=1 adds one case to that cell. The loop unpacks each tuple into three names; it never guesses a reference label from a prediction.

Predict and run the complete counting script

pairs = [("V1", "clear", "clear"),
         ("V2", "clear", "clear"),
         ("V3", "clear", "blocked"),
         ("V4", "blocked", "clear"),
         ("V5", "blocked", "clear"),
         ("V6", "blocked", "blocked"),
         ("V7", "blocked", "blocked"),
         ("V8", "blocked", "blocked")]
labels = ["clear", "blocked"]
index = {label: i for i, label in enumerate(labels)}
counts = [[0, 0], [0, 0]]
for item_id, reference, prediction in pairs:
    counts[index[reference]][index[prediction]] += 1
print(counts)
correct = counts[0][0] + counts[1][1]
print(correct, len(pairs))

Explain the output and assumptions

index maps clear to 0 and blocked to 1. Each paired record adds one to its reference row and prediction column. The script prints [[2, 1], [2, 3]] then 5 8. It assumes unique IDs and only these two labels.

Check IDs and missing or unresolved references before counting; the code does not validate all those conditions.

    A zero cell is an observation, not a guarantee

    A matrix records error patterns without proving their cause.

    Report the full axis convention and evaluation scope

    Always report the evaluated split, number of records, reference and prediction axes, label order and positive class. Reversing the axis order changes positions, not the underlying outcomes.

      Main lesson · Section 8

      Check row totals, column totals and the same-record comparison

      Equal accuracy can conceal a different distribution of mistakes.

      Audit the main totals and accuracy

      Row totals are 3 reference-clear and 5 reference-blocked. Column totals are 4 predicted-clear and 4 predicted-blocked. All four cells sum to 8. Accuracy is the diagonal total divided by the total: 5/8, or 62.5 percent. A separate miniature three-record illustration, clear/clear, clear/blocked and blocked/blocked, has matrix [[1,1],[0,1]] and accuracy2/3. These three records are an illustration here, not the Week12 twenty-case evaluation.

      Compare the alternative on the same eight references

      Another classifier on these same eight reference-labelled records could have matrix [[3,0],[3,2]]. It also gets 5/8 correct, but has zero false positives and three false negatives.

      Our worked classifier has one false positive and two false negatives. Equal accuracy does not settle which error pattern is preferable; consider the task and evidence before choosing.
