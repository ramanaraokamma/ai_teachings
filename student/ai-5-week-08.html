Main lesson · Section 2

Turn every paired prediction error into a penalty

This week uses prediction−target and ordinary MSE with no half factor.

Declare the residual and squared error

A loss assigns a numerical penalty to a prediction compared with a target. For this regression lesson, residual e = prediction - target, and squared error is e squared.

Squaring makes both positive and negative residuals contribute nonnegative penalties. We use ordinary mean squared error without a one-half factor.

Average all cases and retain squared units

The mean squared error, or MSE, is (1 + 1 + 4) / 3 = 2. It summarises these three examples, not every possible future input. If targets use cm, residuals use cm and MSE uses square cm.

    Runnable guarded MSE and its assumptions

    def mse(predictions, targets):
    if not targets or len(predictions) != len(targets):
        raise ValueError("Need equal nonempty sequences")
    errors = [(p - t) ** 2
              for p, t in zip(predictions, targets)]
    return sum(errors) / len(errors)

print(mse([2, 2, 4], [1, 3, 2]))  # 2.0
print(mse([2, 2], [1, 3]))        # 1.0

    The guard prevents silently ignoring an unmatched example or dividing by zero. It still assumes paired, numeric, valid records. Wrong row alignment produces a meaningless comparison even when list lengths agree.

    Trace squares,absolute values and shared denominator

    Main lesson · Section 7

    Repair the denominator before interpreting the score

    Correct predictions still count in the number of evaluated cases.

    Large errors and numerical-target assumptions

    Squaring gives larger residuals more influence: residual 4 contributes 16, four times the penalty of residual 2. This can be useful when large misses matter, but it can also make outliers influential.

    Mean absolute error uses absolute residuals instead; it can rank candidates differently.

    MSE is appropriate here because targets are numerical quantities. A class identifier such as 0, 1 or 2 may merely name a category; its numeric gap does not automatically measure error severity.

    Later classification models need a loss suited to their outputs and task.

    Repair the nonzero-only denominator

    • A learner totals squared errors 1, 0, 9 and divides by 2 because there are two nonzero errors. Correct the MSE.
