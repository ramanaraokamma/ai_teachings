Someone reading the record should be able to recompute a reported MSE and see which decisions each dataset informed.

    Main lesson · Section 6

    Separate a neuron demonstration from a system evaluation

    A correct numerical trace does not supply a population-performance claim.

    Main negative-target challenge and answer

    Challenge: “Your validation error was zero, so why did the final test fail on negative targets?” Response: validation contained only positive inputs; the output max(0,a*x) cannot be negative.

    The final negative cases expose a coverage and architecture limitation. The overall criterion still passed, but that does not remove the failure.

    Stronger-baseline and speed challenges

    Challenge: “Is a neural network better than linear regression?” Response: the supplied baseline was a fixed initial weight, not a fitted line. The evidence establishes improvement relative to that baseline only.

    A fitted signed line is a relevant additional comparison and needs a documented, fair evaluation. Challenge: “Was the candidate faster?” Response: no timing evidence was collected, so speed is unmeasured.

    Separate pictured neuron inputs and scope

    Defend an individual network calculation. At the defence, a team shows a single toy neuron before describing the whole image-pattern experiment.

    Inputs are [2,1]; weights [0.5,-1]; bias 0.2; activation is ReLU, max(0,z). This is a demonstration, not a probability model.

    The picture is a separate arithmetic demonstration, not the scalar capstone’s evaluation. Inputs [2, 1], weights [.5, −1], bias .2 give weighted terms 1 and −1, preactivation .2 and ReLU output .2. Changing only the second input to 2 gives z = −.8 and output 0. There is no supplied class-reference dataset, probability conversion or accuracy denominator for this neuron.

    Its output .2 cannot be called 20% confidence or 20% accuracy.

    Trace multiplication, bias and activation

    A defence should distinguish a traceable network calculation from a claim about classification quality. The neuron transforms supplied numbers; held-out labelled cases are needed to assess the complete system.

    Replay the complete chain and audit each claim

    Check numerical agreement and preserve the limits on what that agreement establishes.

    Current validation-versus-final task

    State the validation selection and frozen final comparison using their correct metrics and scopes.

    Complete executable evidence-chain replay

    """Replay the supplied capstone evidence chain; no population claim."""
train=[(1,2),(2,4)]
validation=[(3,6),(4,8)]
final=[(5,10),(6,12),(-1,-2),(-2,-4)]
def predict(weight,x):return max(0,weight*x)
def mse(weight,rows):return sum((predict(weight,x)-y)**2 for x,y in rows)/len(rows)
records=[]
for rate in [.1,.2]:
    weight=1.0
    history=[]
    for update in [1,2]:
        assert all(weight*x>0 for x,_ in train)
        gradient=sum(2*(weight*x-y)*x for x,y in train)/len(train)
        weight-=rate*gradient
        history.append((update,gradient,weight))
    records.append({'rate':rate,'history':history,'weight':weight,
                    'validation_mse':mse(weight,validation)})
selected=min(records,key=lambda r:(r['validation_mse'],r['rate']))
frozen_weight=selected['weight']
assert frozen_weight==2 and selected['rate']==.2
# No updates or choices below this point use the final targets.
final_ledger=[(x,y,predict(1,x),predict(frozen_weight,x),
               (predict(1,x)-y)**2,(predict(frozen_weight,x)-y)**2)
              for x,y in final]
baseline_mse=mse(1,final)
candidate_mse=mse(frozen_weight,final)
negative_mse=mse(frozen_weight,[(x,y) for x,y in final if x<0])
assert (baseline_mse,candidate_mse,negative_mse)==(20.25,5,10)
print('Validation selection records:',records)
print('Frozen final: x,target,baseline,candidate,baseline squared error,candidate squared error',final_ledger)
print('Final MSE baseline/candidate:',baseline_mse,candidate_mse)
print('Negative-input MSE, 2 rows:',negative_mse)
print('Scope: two positive validation rows; four constructed final rows.')
print('Unmeasured: timing, energy, fitted-line comparison, independent revised-model performance.')
# Separate supported comparison: not the main scores.
absolute=8-2;relative=absolute/8
assert (absolute,relative)==(6,.75)
print('Separate supported reduction:',absolute,'MSE units;',100*relative,'% relative MSE reduction')
# Pictured neuron: an activation, not a probability or an accuracy percentage.
def neuron(second):
    z=2*.5+second*(-1)+.2
    return z,max(0,z)
assert abs(neuron(1)[0]-.2)<1e-12 and neuron(2)[1]==0
print('Picture original z/output:',neuron(1),'changed:',neuron(2))
