A root question, branches and leaves

A decision tree asks a feature question and follows a branch to a prediction. A tree with one question has depth one and is sometimes called a stump. In Week10 the Tower1 rule was supplied. Here the class names are still declared in advance, but training labels determine which question is selected and which class prediction is stored at each leaf.

The feature meanings and complete training table

Our six fictional training rows have two binary sensor flags available before prediction: near and tall. A value of 1 means that flag is present; 0 means absent. The reviewed scene label is separate.

Each row represents a different trip on a familiar route, including rows with identical values. Similar readings can have different scene labels. These are teaching examples, not robot control instructions.

The candidate order, majority rule and tie conventions

Try near first and tall second. For each question, group the training rows by 0 and 1, then predict each group’s majority label; choose clear for tied label counts.

Count all training mistakes and keep the first question if scores tie. Stop after one question. This is our stated classroom fitting procedure.

Main lesson · Section 3

Read the complete depth-one fitting program

This classroom learner minimises total training mistakes, not branch-size balance.

Understand the branch counts and strict comparison

Each row stores near at index0, tall at index1 and its reference label at index2. The inner list comprehension gathers training labels for one candidate’s0 or1 branch. majority counts those labels and returns clear when counts tie. leaves maps each branch value to its predicted class. Score every training row once against its branch prediction. The strict < replacement means an equally scoring later question cannot replace the first. Fitting ends before any validation labels are used.

Predict and run both candidate comparisons

rows = [(1, 0, "blocked"), (1, 1, "blocked"),
        (1, 0, "blocked"), (0, 1, "clear"),
        (0, 0, "clear"), (0, 1, "blocked")]
def majority(labels):
    if labels.count("blocked") > labels.count("clear"):
        return "blocked"
    return "clear"
best_errors = len(rows) + 1
for feature in [0, 1]:
    leaves = {}
    for value in [0, 1]:
        labels = [row[2] for row in rows
                  if row[feature] == value]
        leaves[value] = majority(labels)
    errors = 0
    for row in rows:
        if leaves[row[feature]] != row[2]:
            errors = errors + 1
    print(feature, errors)
    if errors < best_errors:
        best_errors = errors
        tree = (feature, leaves)
print(tree[0], tree[1][0], tree[1][1])

Explain the selected near tree

Feature 0 is near; feature 1 is tall; row[2] is the label. Output is 0 1, then 1 2, then 0 clear blocked. Near makes one training mistake: near=0 contains two clear labels and one blocked, so that leaf predicts clear.

Near=1 contains three blocked labels. Tall makes two mistakes because both its groups have a blocked majority.

Keep assumptions and the depth limit explicit

The stored tree contains the chosen feature and its two learned leaves. The code assumes nonempty data, binary flags, allowed labels and examples on both branches of each candidate.

An empty branch would need a declared fallback; this small example does not implement one. The score is total training mistakes, not an average giving small and large branches equal weight.

This is an explicitly limited depth-one learner. General tree algorithms can repeat split selection within branches and often use impurity criteria such as Gini. Our code does not implement that full procedure.

Keeping the scope small lets you inspect every decision.

rows = [(1, 0, "blocked"), (1, 1, "blocked"),
        (1, 0, "blocked"), (0, 1, "clear"),
        (0, 0, "clear"), (0, 1, "blocked")]
def majority(labels):
    if labels.count("blocked") > labels.count("clear"):
        return "blocked"
    return "clear"
best_errors = len(rows) + 1
for feature in [0, 1]:
    leaves = {}
    for value in [0, 1]:
        labels = [row[2] for row in rows
                  if row[feature] == value]
        leaves[value] = majority(labels)
    errors = 0
    for row in rows:
        if leaves[row[feature]] != row[2]:
            errors = errors + 1
    print(feature, errors)
    if errors < best_errors:
        best_errors = errors
        tree = (feature, leaves)
print(tree[0], tree[1][0], tree[1][1])

validation = [(1, 1, "blocked"), (0, 0, "clear"),
              (0, 1, "blocked"), (1, 0, "clear")]
feature, leaves = tree
predictions = [leaves[row[feature]] for row in validation]
reference = [row[2] for row in validation]
print("tree", predictions, sum(p == y for p, y in zip(predictions, reference)), len(reference))
baseline = majority([row[2] for row in rows])
print("baseline", baseline, sum(baseline == y for y in reference), len(reference))
