Main lesson · Section 2

Read the case-sensitive vocabulary and longest-match contract

Token IDs name entries; they are not meanings or similarity scores.

The complete toy tokenizer rule

Tokens need not be words. A classroom tokenizer can use an exact, case-sensitive vocabulary and greedily choose the longest matching token from left to right. This is a toy rule, not a claim about every production tokenizer.

Define IDs: 0=end, 1=cat, 2=c, 3=a, 4=t, 5=s, 6=space, 7=sat. The space token represents one literal space. The end token is a special terminator, not ordinary text.

At each position choose the longest matching ordinary token. If no token matches, stop and report the unsupported character and its position. Do not delete the character or guess a replacement.

IDs identify entries; a larger ID does not mean a token is more valuable or more similar.

The ID and special-token reference

0endSpecial terminator; not an ordinary text match
1catThree ordinary characters
2 / 3 / 4 / 5c / a / t / sFour separate single-character entries
6one literal spacePreserve the actual space character

Main lesson · Section 6

Compare vocabularies, then a separate book phrase

Do not mix the cat vocabulary with the book/books vocabulary.

Count character-only versus original cat tokens

A character-only vocabulary c,a,t,s,space could encode cats sat as c,a,t,s,space,s,a,t: eight text tokens. The original vocabulary uses four. Both decode to the same source text.

Sequence length is a property of the text, vocabulary and encoding rule together. Counts from different tokenizers are not automatically comparable.

In this vocabulary, sat is chosen over s because it is longer. The toy longest-match rule is defined explicitly. Real tokenizers may use different algorithms, byte encodings and special-token policies.

Never infer an unknown tokenizer’s count from word count alone.

      The complete toy encoder and all investigation inputs

      vocabulary = {1: "cat", 2: "c", 3: "a", 4: "t", 5: "s", 6: " ", 7: "sat"}
def encode(text, entries):
    ids = []
    position = 0
    order = sorted(entries, key=lambda number: (-len(entries[number]), number))
    while position < len(text):
        found = None
        for token_id in order:
            if text.startswith(entries[token_id], position):
                found = token_id
                break
        if found is None:
            return ids, (position, text[position])
        ids.append(found)
        position += len(entries[found])
    return ids, None
for text in ["cats sat", "c at", "Cat", "cat!"]:
    ids, error = encode(text, vocabulary)
    print(repr(text), ids, error)
    if error is None:
        decoded = "".join(vocabulary[token_id] for token_id in ids)
        print("decoded", repr(decoded), "text tokens", len(ids))
character_entries = {number: text for number, text in vocabulary.items() if len(text) == 1}
ids, error = encode("cats sat", character_entries)
print("character-only", ids, len(ids), error)
