Read the timing protocol before comparing the models

Quality and resources together

A neural model can be faster yet fail the task’s accuracy requirement. Training cost and prediction cost are different: training updates parameters, while inference uses the fitted model.

Compare quality and resources together under a declared test, rather than calling a model efficient from one small number.

    Convert a whole-pass duration into two resource summaries

    Seconds per example and examples per second use opposite ratios.

    Original runnable timing helper

    from math import isfinite
from statistics import median

def timing_summary(seconds, count):
    if count <= 0 or not seconds:
        raise ValueError("Need examples and timed passes")
    if any(not isfinite(t) or t <= 0 for t in seconds):
        raise ValueError("Times must be finite and positive")
    middle = median(seconds)
    ms_per_example = 1000 * middle / count
    examples_per_second = count / middle
    return middle, ms_per_example, examples_per_second

print(timing_summary([2.0, 2.2, 1.8], 100))
print(timing_summary([1.2, 1.1, 1.3], 100))

    Different percentage denominators

    The code assumes a positive integer example count and numeric times. A outputs (2.0, 20.0, 50.0); B outputs approximately (1.2, 12.0, 83.33). Retain full precision until display.

    The time reduction is (20 - 12) / 20 = 40 percent, while throughput rises by about 66.67 percent. These are different denominators.

    What amortised time cannot measure

    Amortised time does not reveal the slowest request or a latency percentile. In a batched or concurrent workload, total time divided by count is not an individual request’s waiting time.

    Record per-request timings if the requirement concerns latency; keep batch size and concurrency explicit.

      Main lesson · Section 7

      Count parameters without calling that peak memory

      A storage calculation and a runtime measurement answer different questions.

      Dense weights, biases and raw bytes

      A fully connected layer with m inputs and n outputs has m times n weights and n biases, assuming every output has one bias. A network with dimensions 4 to 3 to 2 has (4 times 3 + 3) + (3 times 2 + 2) = 23 parameters.

      At four bytes per parameter, its raw parameter payload is 92 bytes.

      Complete layer-by-layer account

      File size, runtime memory and energy limits

      That is not the saved file size or peak runtime memory. A file can contain metadata, and inference also needs activations and buffers. Training may additionally store gradients and optimiser state.

      Record whether a memory measurement refers to the model, the process, an accelerator or the whole device. Parameter count alone does not establish speed.

      Runtime alone does not establish energy use or carbon emissions either. Those require additional measurements and declared assumptions, such as power over time and the electricity source.

      Report what you measured rather than converting fewer parameters into an unsupported energy claim.

      Complete executable audit

      """Arithmetic on invented timing observations; this is not a benchmark."""
from math import isfinite
from statistics import median, mean

def timing_summary(seconds, count, method='median'):
    if type(count) is not int or count <= 0 or not seconds:
        raise ValueError('Need a positive integer count and timed passes')
    if any(not isfinite(t) or t <= 0 for t in seconds):
        raise ValueError('Times must be finite and positive')
    if method not in ('median','mean'):
        raise ValueError('Unknown summary method')
    duration = (median if method=='median' else mean)(seconds)
    return duration, 1000*duration/count, count/duration

def parameters(widths):
    if len(widths)<2 or any(type(n) is not int or n<=0 for n in widths):
        raise ValueError('Need at least two positive integer layer widths')
    weights=sum(m*n for m,n in zip(widths,widths[1:]))
    biases=sum(widths[1:])
    return weights,biases,weights+biases

a=timing_summary([2.0,2.2,1.8],100)
b=timing_summary([1.2,1.1,1.3],100)
def eligible(correct,count,ms,minimum_correct,maximum_ms):
    return correct>=minimum_correct and ms<=maximum_ms
assert a==(2.0,20.0,50.0) and b[:2]==(1.2,12.0)
assert eligible(92,100,a[1],91,25) and not eligible(90,100,b[1],91,25)
assert eligible(90,100,b[1],90,25)
print('Main median summaries: seconds, ms/example, examples/second',a,b)
print('Relative time reduction:',(a[1]-b[1])/a[1])
print('Relative throughput increase:',(b[2]-a[2])/a[2])
print('Timed passes per model: 3 × 100 = 300 prediction executions')
print('Plus warm-up: 100 more executions; quality sample remains 100 distinct cases')
w,bi,total=parameters([4,3,2])
assert (w,bi,total)==(18,5,23)
print('Dense weights, biases, total, raw bytes:',w,bi,total,total*4)
p=timing_summary([.32,.40,.48],40,'mean')
q=timing_summary([.20,.24,.28],40,'mean')
assert abs(p[1]-10)<1e-12 and abs(q[1]-6)<1e-12
