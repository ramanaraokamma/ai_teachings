Main lesson · Section 2

State the fitting procedure before comparing results

The tower labels belong to this fictional task and use height as the only feature.

The supplied towers and labels

Four imaginary paper towers have heights 2, 4, 6 and 8 centimetres. Their supplied labels are short, short, tall and tall. These labels belong to this classroom task; they are not a universal definition of tall.

We will fit a rule using height as its only input.

The candidates and declared tie rule

Every candidate predicts tall when height is at least its threshold and short otherwise. Compare thresholds 3, 5, 6 and 7 centimetres. The fitting procedure chooses the fewest disagreements with the four labels.

If candidates tie, choose the smaller threshold. Write these choices before comparing results.

Count disagreements separately for every candidate

For each candidate, start its count at zero. For each example, predict with that candidate, compare with the supplied label, and add one only for a disagreement. After all four examples, record the count.

Then move to the next candidate with a fresh count. This uses the conditions and repetition you have already traced.

Prepare the comparison

  • Before calculating, write the candidate thresholds, comparison phrase and tie policy. For each candidate, where does its error count begin, and when should you reset that count?

The first four rows are fitting examples. The final row asks what the two tied candidates predict at a height missing from that set. Our tie rule selects 5, so the selected model predicts tall at 5.

Main lesson · Section 7

Best among these candidates has a limited meaning

Features, candidate families and label policies remain human choices.

Keep the comparison scope explicit

The best candidate means best among the candidates compared, using this counting rule and these recorded labels. A different candidate family, feature or label policy might give a different result.

People chose those ingredients; fitting does not remove those choices.

Inspect conflicting labels for identical inputs

If two records with identical input height have different labels, any deterministic rule using only that height gives them the same prediction. It must disagree with at least one label.

Investigate the records and task definition instead of silently changing a label to make the model look perfect.

Repair an unsupported future guarantee

  • CLAIM A The model discovers the one true rule hidden in nature.

  • CLAIM B One example is enough to learn a reliable category.

STRONG ANSWER FRAME I claim ______ because the evidence shows ______. The process is ______. One limit is ______.
