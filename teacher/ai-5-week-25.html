Explain and model the mechanism

Model Sequence representations using the supplied case, labelled mechanism and reasoning. Make the scope of each conclusion explicit.

Explain Sequence representations · 1

Use fictional robot event logs whose symbols are GO, TURN and STOP. The task asks whether the final real event is STOP. This is a representation exercise, not a claim that an event log proves a robot is safe.

GO then STOP and STOP then GO contain the same symbols but have different final events.

Explain Sequence representations · 2

A count vector discards order, so no deterministic rule using only the first two count vectors can distinguish their answers. A sequence of IDs preserves order if we retain each position.

Declare the vocabulary: PAD = 0, UNK = 1, GO = 2, TURN = 3 and STOP = 4. PAD is reserved for added storage positions; UNK represents a real but unrecognised symbol.

IDs are names, not measured amounts. STOP having ID 4 does not make it twice as much as GO with ID 2. Changing the vocabulary requires changing every consumer consistently.

Do not interpret numerical distance between IDs as semantic similarity.

Store each log in four positions, padding on the right. A mask value 1 marks a real position and 0 marks padding. The encoder rejects empty logs, logs longer than four, and literal reserved markers.

Other unrecognised symbols become UNK and still receive mask 1.

Explain Sequence representations · 3

The code assumes a list of symbol strings and uses exact spelling. It does not fit a vocabulary from data.

If a future project fits vocabulary choices or frequency cutoffs, derive those choices from training data and apply the saved encoding consistently to validation and final cases.

TermMeaning
SequenceAn ordered list of elements in which positions can matter
Token IDA numerical identifier assigned to a symbol by a vocabulary
PaddingPlaceholder positions added to make stored sequences the same length
MaskA list marking which stored positions are real inputs and which are placeholders

Run the investigation and diagnose misconceptions

Run the Sequence representations investigation and use the first unsupported step to choose a teaching response.

Larger token IDs mean more of a concept: IDs identify symbols; their arithmetic sizes have no declared semantic meaning.

Zero always means missing data: A measured zero can be real; the mask determines which positions contribute.

A mask automatically fixes every model computation: The relevant operation must actually use the mask, and later aggregation can still discard order.

W4 Apply a fresh schema independently

Workbook question · W4

Use PAD = 0, UNK = 1, OPEN = 2, CLOSE = 3, CHECK = 4 and five stored positions. Encode OPEN CHECK CLOSE and give its mask and final real position. Separately, sensor values [0, 6, 3, 0, 0] have that same mask.

Calculate their masked mean and the incorrect mean over all five slots.

Teacher reasoning · W4

Teacher explanation: IDs [2, 4, 3, 0, 0], mask [1, 1, 1, 0, 0]; final real position 2 contains CLOSE. Masked sensor mean is (0 + 6 + 3) / 3 = 3. Unmasked mean is 9 / 5 = 1.8. The measured zero must count in the denominator.

W5 Audit length and empty input

Workbook question · W5

The encoder receives five events ending in STOP, then an empty log. What should it do under the lesson contract? Why should a program not simply crop the first and assume a final event for the second?

Teacher reasoning · W5

Teacher explanation: It rejects both: one exceeds four real events and the other has none. Cropping can remove the final event and change the task answer.

An empty log has no final real position; the program needs an explicit policy rather than an invented event.
