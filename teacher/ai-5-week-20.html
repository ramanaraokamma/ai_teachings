Explain and model the mechanism

A small fictional RGB image has height 2 pixels, width 2 pixels and three channels ordered red, green, blue. Store it as image[row][column][channel], abbreviated HWC. Use zero-based indices: the top row is 0, the left column is 0, and red, green and blue are channels 0, 1 and 2. Each stored component is an integer from 0 to 255.

The shape is 2 by 2 by 3. There are four pixels and twelve channel values. The blue component of the bottom-left pixel is image[1][0][2] = 255. A single channel is a plane of values across positions; it is not a separate photograph or a label.

Shape needs a schema. A grayscale image might be stored as H by W or H by W by 1. An RGB image uses three channels here; other formats can include additional channels. Declare the format instead of assuming every three-dimensional array means the same thing.

A channel-first layout uses image[channel][row][column], abbreviated CHW. Our image then has shape 3 by 2 by 2. A correct conversion preserves the rule chw[c][r][k] = hwc[r][k][c]. The code assumes a nonempty rectangular image with exactly three values per pixel.

Reading nested values in order and merely regrouping them into a new shape does not perform this axis conversion. The first four flattened HWC values are [255, 0, 0, 0]. A naive regrouping makes these the first channel plane, but the correct red plane is [[255, 0], [0, 255]]. Shape agreement alone cannot detect this mistake.

TermMeaning
TensorA numerical array with a declared set of axes
ChannelOne component plane of an image such as red green or blue
Axis orderThe sequence of meanings assigned to array dimensions
Value scalingA declared numerical conversion applied to stored values

Guided: top-right is [0, 255, 0] and bottom-right is [255, 255, 255]. The top-right green value is hwc[0][1][1] or chw[1][0][1], both 255. Exit: shape alone misses both errors. Check the top-left RGB pixel is red before scaling and that a raw value 255 becomes exactly 1 under one declared division, rather than approximately 0.00392.

A pictorial worked case: Image tensors and channels

Move colour values between tensor layouts without changing the pixels.

The facts we will use

Toy RGB image has 2 rows, 1 column. Top pixel [1, 4, 7]; bottom [2, 5, 8]. HWC means height, width, channel.

All inputs and outcomes in this worked example are invented classroom data; no real model run is claimed.

Why this result follows

A tensor is an array with named dimensions. HWC orders height, width and colour; CHW puts colour first. Rearranging the layout changes where values are stored, not the colour measurement itself. Trace a named pixel through both layouts using zero-based indices. Adding a batch dimension counts images and does not add a new colour channel.

What this example does not establish

Shape consistency does not prove correct colour order or value range; document channel names and preprocessing.

Prediction: Batch shape is [3, 2, 1, 3].

Reason: The new first dimension counts images; it does not add a fourth colour channel.

Teacher guide · 4 of 7

Run the investigation and diagnose misconceptions

Three channels mean three images: Channels are component planes at matching spatial positions in one image.

Reshaping automatically changes axis meanings correctly: Axis permutation must preserve coordinate correspondence; regrouping a flattened list can mix positions and colours.

Every conversion to a smaller number preserves information: Exact fixed scaling differs from rounding and channel averaging, which can collapse distinct values.

Use Section 9 for the evidence ledger. Add a boundary or missing-input case and record the expected response before checking. More successful repeats of one case do not establish wider coverage.

W2 Audit an axis conversion

A program flattens the lesson HWC array and groups the first four values into a 2 by 2 red plane. Give that incorrect plane and the correct plane. Identify a position where they disagree.

Teacher explanation: The incorrect plane is [[255, 0], [0, 0]]. The correct red plane is [[255, 0], [0, 255]]. They disagree at row 1 column 1. Regrouping consecutive values does not transpose axes.

W3 Check scaling and lost colour

Scale [255, 128, 0] by 255, keeping the middle value as a fraction. Then calculate the classroom RGB means of pure red and pure green. Which operation loses the distinction between those colours?

Teacher explanation: Scaling gives [1, 128/255, 0]. Both RGB means are 85, so averaging loses the red versus green distinction. Exact fixed scaling preserves the triplet distinction.

W4 Convert a new image independently

A one-row two-column RGB image has pixels [10, 20, 30] then [40, 50, 60]. State its HWC shape and all three CHW planes. Give the green value at row 0 column 1 in both layouts. A batch contains four copies: give its NHWC shape and total channel-value count.

Teacher explanation: HWC shape is 1 by 2 by 3. CHW planes are [[10, 40]], [[20, 50]], [[30, 60]], giving shape 3 by 1 by 2. hwc[0][1][1] and chw[1][0][1] both equal 50. Batch shape is 4 by 1 by 2 by 3, containing 24 values.

W5 Design revealing pipeline checks

The lesson image is loaded with red and blue exchanged, then scaled twice. Give two expected checks that would expose these errors even though the shape is correct.

Teacher explanation: Before scaling, the top-left pixel must be [255, 0, 0], not [0, 0, 255]. A known raw component of 255 must become 1 after scaling once; approximately 0.00392 indicates division twice. Test named values and positions as well as dimensions.

Independent assessment and fresh retry

W4 requires three planes, both coordinate references to value 50, NHWC shape 4 by 1 by 2 by 3 and 24 values. Fresh retry: a two-row one-column image contains [3, 6, 9] above [12, 15, 18]. HWC shape is 2 by 1 by 3. CHW planes are [[3], [12]], [[6], [15]], [[9], [18]]. The bottom blue component is hwc[1][0][2] = chw[2][1][0] = 18. A batch of three has NHWC shape 3 by 2 by 1 by 3 and 18 values.
