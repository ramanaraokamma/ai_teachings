Explain the mechanism

Explain the mechanism

Trace the information, fitted behavior, and evaluation proof separately.

QUESTION Compare trivial accuracy with minority-class recall.

MODEL IDEA Accuracy can be dominated by a common class and hide failure on a rare but important class.

PROOF NEEDED Use an unseen case, visible calculation, error analysis, and a stated limitation.

UNDER THE HOOD Test set has 95 healthy and 5 diseased leaves. Always predicting healthy gives 95 ÷ 100 = 95% accuracy.

Draw a fresh data → model → prediction → evaluation trace:

Predict first. Then check each step. A correct answer without visible evidence cannot be audited.

STEP 1 Test set has 95 healthy and 5 diseased leaves.

STEP 2 Always predicting healthy gives 95 ÷ 100 = 95% accuracy.

STEP 3 It finds 0 of 5 diseased leaves, so diseased recall = 0%.

STEP 4 Report class counts and recall; redesign data or use only where misses are acceptable.

CHECK Verify the denominator, unit, split, class definition, and data version before interpreting a score.

Concrete teaching case

Calculate and critique accuracy.

Exact explanation to model

Explain the added worked example

Accuracy counts all correct predictions and divides by all evaluated examples. Each example has equal weight, so a common class contributes more to the score. A high result can hide failure on a rare class. This week keeps the confusion matrix visible and checks both classes separately.

New fictional training data has 16 clear and 4 blocked labels. Its majority baseline predicts clear for every query; choose that rule from training, not evaluation labels. A separate evaluation set also contains 16 clear and 4 blocked cases. A frozen candidate and the baseline are evaluated on the same 20 records.

Rows are references and columns are predictions, ordered clear then blocked. Blocked is positive. Both methods get 16/20=80 percent accuracy. The baseline misses all four blocked cases. The candidate finds all four but falsely flags four clear cases. The same score conceals a different tradeoff.

The output is baseline 80.0 50.0, then candidate 80.0 87.5. In each output line the first percentage is ordinary accuracy and the second is balanced accuracy. For the candidate, the clear-class correct fraction is 12/16=75 percent and the blocked-class fraction is 4/4=100 percent. Their equal average is 87.5 percent.

For the baseline, those fractions are 16/16=100 percent and 0/4=0 percent, averaging 50 percent. The code assumes a two-by-two table of nonnegative integer counts in the stated order. It stops when either reference class is absent. Then report the observed counts and the unavailable class result; do not invent a denominator or silently substitute zero.

Key terms

TermMeaning
Class imbalanceUnequal numbers of examples in different classes
Majority baselineA rule that always predicts the most common training label
Class-specific correct fractionCorrect predictions for one reference class divided by the number of examples of that class
Balanced accuracyThe average of the class-specific correct fractions with equal weight for each class

Balanced accuracy is a metric choice, not a repair to the classifier or a guarantee of safety. It gives classes equal influence in this summary; it does not encode the actual consequences of false alarms and missed cases. Four blocked evaluation examples are also too few for a strong general claim.

Diagnose and reteach

MISCONCEPTION TO REPAIR A classifier with 95% accuracy is excellent in every practical situation.

For guessing, return to given facts and request a trace. For vocabulary without application, use one example and one non-example. For arithmetic errors, check the setup before the calculation. Finish with a different uncoached case before recording mastery.

Address these additional misconceptions

High accuracy means both classes work well: A common class can dominate the overall count. Inspect each reference-class denominator and its errors.

Balanced accuracy fixes the model: It changes the summary weighting, not any prediction or underlying error.

An absent class has zero measured performance: Its fraction has a zero denominator and is unavailable. Report missing coverage rather than inventing a value.

Explanations for the additional workbook examples

W1 Score the majority baseline

Training has 16 clear and 4 blocked labels. State the majority rule. On the worked evaluation, give its matrix, accuracy, false positives and false negatives with blocked positive. Explain why 80 percent is incomplete.

The training-majority rule always predicts clear. Matrix [[16,0],[4,0]] gives 16/20=80 percent, FP=0,FN=4. It misses all four blocked cases, so the overall score hides complete failure on that evaluated class.

W2 Compare both class fractions

For the worked candidate [[12,4],[0,4]], give ordinary accuracy, both class-specific correct fractions, balanced accuracy, false positives and false negatives. Compare with the baseline.

Accuracy 16/20=80 percent. Clear fraction 12/16=75 percent; blocked fraction 4/4=100 percent; balanced accuracy (75+100)/2=87.5 percent. FP=4,FN=0. Baseline accuracy is also 80 percent but balanced accuracy is 50 percent with FP=0,FN=4.

W3 Explain a changed class mix

For the illustrative 8-clear 8-blocked set, use baseline [[8,0],[8,0]] and candidate [[6,2],[0,8]]. Calculate ordinary and balanced accuracy for each. Explain what stayed fixed and what this example does not prove.

Baseline ordinary 8/16=50 percent and balanced (100+0)/2=50 percent. Candidate ordinary 14/16=87.5 percent and balanced (75+100)/2=87.5 percent. Within-class fractions stayed fixed while class counts changed. This arithmetic assumption does not prove unchanged real-world behavior on a new population.

W4 Assess a new comparison independently

New training labels have a clear majority. A separate evaluation has 18 clear and 2 blocked records. The always-clear baseline is [[18,0],[2,0]] and candidate is [[15,3],[1,1]], with reference rows and clear then blocked on both axes. Calculate ordinary accuracy, both class fractions and balanced accuracy for each. Give candidate FP and FN, then explain why the metrics do not choose an automatic winner.

Baseline accuracy 18/20=90 percent; class fractions 100 percent and 0 percent; balanced accuracy 50 percent. Candidate accuracy 16/20=80 percent; clear fraction 15/18=5/6 about 83.3 percent, blocked fraction 1/2=50 percent; balanced accuracy (5/6+1/2)/2=2/3 about 66.7 percent. Candidate FP=3,FN=1. It finds one blocked case but adds three false alarms; task consequences and the small sample matter.

W5 Limit claims from missing classes

An evaluation contains ten clear cases and no blocked cases. All predictions are clear. State ordinary accuracy, explain why blocked performance is unavailable, and describe how our code handles the missing class.

Ordinary accuracy is 10/10=100 percent on the observed clear cases. The blocked-class fraction has denominator zero, so it cannot be measured. Our two-class summary function stops with ValueError; report the missing coverage instead of claiming perfect performance on both classes.
