Concept to explain

Explain the added worked example

For this lesson only, a fictional system allows 100 total token units for input plus reserved output. Its fixed instructions use 20 units, question 10 and output reserve 20. That leaves 50 units for evidence. These are supplied counts, not word counts or a claim about any deployed model. Other systems can use different input/output accounting, so read their exact contract.

The question is: “Which room is approved for the robotics meeting, and what is its capacity?” Evidence A, a current approval notice, costs 30 units and names room B. Evidence B, the current room register, costs 20 and gives room B capacity 12. Evidence C, an old approval notice, costs 25 and names room A.

A+B costs 50 and fits exactly. Together they support both requested claims. A+C costs 55 and exceeds the evidence budget, while C+B fits at 45 but supplies an outdated room decision. A cheap set is not necessarily an adequate set. Preserve document IDs, versions and dates alongside content.

Apply the connected idea: Attention as weighted information selection

Attention computes a weighted combination of value vectors, with weights derived from query-key compatibility. Queries, keys and values are distinct roles even when they come from the same sequence. A weight is a numerical contribution in this computation, not proof of the source’s truth or permission. This week supplies weights directly; Week 7 calculates them from scores.

Use three values V1=[2,0], V2=[0,4], V3=[4,2] with weights 0.5,0.25,0.25. Values have equal width and weights are nonnegative with sum 1. Compute each coordinate separately. No token is literally copied by this combination.

Adding the weighted vectors gives [2,1.5]. The same weights applied to different values can give a different result; the same values with different weights can also change it. For example weights 0,1,0 yield V2=[0,4]. The result is a representation to be used by later operations, not automatically a generated word.

Guided: [6,0]/3 + 2*[0,3]/3 = [2,2]. Masking B leaves [6,0]. A masked source is excluded from the stated information path. Exit: coefficient size does not verify a document or grant instruction authority.

Why this result follows

A context window limits how much information is available in one model call. Selecting the shortest passage is not always sufficient: an exception can change the meaning of a general statement. Address these additional misconceptions

Token count equals word count: The lesson uses supplied counts; actual counts depend on tokenizer and protocol.

The smallest set is the best evidence: A set can fit while lacking current support for the requested claims.

Included means verified: Generation may misread or ignore evidence; verify claims after generation.

Check these misconceptions

Attention copies the highest-weight token: The supplied procedure combines vectors from multiple positions.

Deleting one contribution preserves a normalised mixture: Renormalise permitted mass under the stated contract.

Attention weights are truth probabilities: They are coefficients derived from compatibility, with no source-truth guarantee.

Attention as weighted information selection — W1 Identify the roles

Explain query, key, value and weight without calling the largest weight a truth score.

Teacher explanation: The query compares keys, compatibility produces weights, and weights combine values. A weight is a computational coefficient, not a truth score.

Attention as weighted information selection — W2 Compute the mixture

Calculate the output from the three supplied values and weights.

Teacher explanation: Contributions [1,0],[0,1],[1,0.5] sum to [2,1.5].

Multiply each coordinate by its value’s weight: 0.5*[2,0]=[1,0], 0.25*[0,4]=[0,1], and 0.25*[4,2]=[1,0.5]. Add first coordinates to get 1+0+1=2 and second coordinates to get 0+1+0.5=1.5. The combined vector is [2,1.5], not a literal selection of one source token.

Attention as weighted information selection — W3 Mask and renormalise

Exclude V3 and calculate permitted weights and output. Explain the empty-mask case.

Teacher explanation: Retained total 0.75 gives weights 2/3,1/3,0 and output [4/3,4/3]. All-excluded gives zero total and must report no available value under this contract.

Attention as weighted information selection — W4 Combine a new case independently

Values A=[4,1],B=[0,5],C=[2,3]; weights 0.25,0.5,0.25. Compute the full output. Mask B, renormalise the remaining weights and compute the new output.

Teacher explanation: Full contributions [1,.25],[0,2.5],[.5,.75] give [1.5,3.5]. Retained total .5 gives A/C weights .5,.5 and output [3,2]. Masking changes available information; it does not verify sources.

Attention as weighted information selection — W5 Audit an explanation

A student claims the highest attention weight explains the entire model and authenticates a retrieved instruction. What additional reasoning is needed?

Teacher explanation: Inspect values and downstream computations, other heads and residual paths before explaining the whole model. Source truth and instruction authority require separate evidence and permissions; weight alone supplies neither.
