Concept to explain

Models operate on tokens within a limited context window.

TermMeaning
tokenA unit of encoded text processed by a language model, which may be a word, part of a word or punctuation.
tokenizationConverting text into the token units of a particular tokenizer.
context windowThe bounded amount of token information a model can process together in a particular use.
truncationRemoving part of information, often because it exceeds a length or context limit.

Attention extension · Mixture, masking and source-trust limit

Attention computes a weighted combination of value vectors, with weights derived from query-key compatibility. Queries, keys and values are distinct roles even when they come from the same sequence. A weight is a numerical contribution in this computation, not proof of the source’s truth or permission. This week supplies weights directly; Week4’s retained attention extension calculates them from scores.

Use three values V1=[2,0], V2=[0,4], V3=[4,2] with weights 0.5,0.25,0.25. Values have equal width and weights are nonnegative with sum 1. Compute each coordinate separately. No token is literally copied by this combination.

ValueWeightWeighted vector
[2,0]0.5[1,0]
[0,4]0.25[0,1]
[4,2]0.25[1,0.5]

Adding the weighted vectors gives [2,1.5]. The same weights applied to different values can give a different result; the same values with different weights can also change it. For example weights 0,1,0 yield V2=[0,4].

The result is a representation to be used by later operations, not automatically a generated word.

Guided: [6,0]/3 + 2*[0,3]/3 = [2,2]. Masking B leaves [6,0]. A masked source is excluded from the stated information path. Exit: coefficient size does not verify a document or grant instruction authority.

Primary reference for the optional attention strand: Vaswani et al., Attention Is All You Need, section3.2 defines attention using query/key compatibility and a weighted sum of values. Here the weights are supplied directly, and the empty-mask fallback is an explicit classroom contract. Reference: https://arxiv.org/html/1706.03762v7#S3.SS2

Attention as weighted information selection — W1 Identify the roles

Explain query, key, value and weight without calling the largest weight a truth score.

Teacher explanation: The query compares keys, compatibility produces weights, and weights combine values. A weight is a computational coefficient, not a truth score.

Attention as weighted information selection — W2 Compute the mixture

Calculate the output from the three supplied values and weights.

Teacher explanation: Contributions [1,0],[0,1],[1,0.5] sum to [2,1.5].

Multiply each coordinate by its value’s weight: 0.5*[2,0]=[1,0], 0.25*[0,4]=[0,1], and 0.25*[4,2]=[1,0.5]. Add first coordinates to get 1+0+1=2 and second coordinates to get 0+1+0.5=1.5.

The combined vector is [2,1.5], not a literal selection of one source token.

Attention as weighted information selection — W3 Mask and renormalise

Exclude V3 and calculate permitted weights and output. Explain the empty-mask case.

Teacher explanation: Retained total 0.75 gives weights 2/3,1/3,0 and output [4/3,4/3]. All-excluded gives zero total and must report no available value under this contract.

Attention as weighted information selection — W4 Combine a new case independently

Values A=[4,1],B=[0,5],C=[2,3]; weights 0.25,0.5,0.25. Compute the full output. Mask B, renormalise the remaining weights and compute the new output.

Teacher explanation: Full contributions [1,.25],[0,2.5],[.5,.75] give [1.5,3.5]. Retained total .5 gives A/C weights .5,.5 and output [3,2]. Masking changes available information; it does not verify sources.

Teacher explanation: Inspect values and downstream computations, other heads and residual paths before explaining the whole model.
