Definitions and family contract

Testing many hypotheses creates more chances for false discoveries. A family rule must be specified before selecting attractive p-values.

For this exercise use Bonferroni: family alpha .05 divided by number of tests m; reject each test when its valid p-value is at most .05/m. This controls the family error by a bound without requiring independent tests.

Why the bound works: with m tests, each true null has false-rejection probability at most alpha/m when its p-value is valid. The probability of any false rejection is at most the sum of those probabilities. There are at most m true nulls, so the sum is at most m × alpha/m = alpha. This is an upper bound, not a measured error frequency, and it does not require independence across tests.

Main: 0.05/5 = 0.01, so only 0.009 rejects; 0.012 would reject only under the unadjusted 0.05 rule. Picture: 0.05/6 = 1/120, so only 0.004 rejects. Changed ten-test family: cutoff 0.005; only 0.004 among the six supplied values rejects. Four missing outcomes cannot be classified. Independent task: 0.05/4 = 0.0125, so only 0.01 rejects. Equality is included.

The union bound needs valid individual p-values, not independent tests; it bounds the chance of any false rejection, not the percentage of reported discoveries that are false. No effect size, actual data or null-truth probability is supplied.

Optional local lab: predict the printed result before running this standalone Python 3 example. Change one relevant boundary input, record the outcome and state the contract or statistical assumptions.

The program uses fictional values and the Python standard library; it performs no external operations.

def bonferroni(p_values, alpha=0.05):
    if not p_values or not 0 < alpha < 1 or any((not 0 <= p <= 1 for p in p_values)):
        raise ValueError('test settings')
    threshold = alpha / len(p_values)
    return (threshold, [p <= threshold for p in p_values])

print(bonferroni([.009, .012, .3, .4, .8]))
