Explain the added worked example

Explain the added worked example · 1

“Write something good about our club” leaves many decisions unstated. Who will read it? Which facts may be used? What must the output contain? A more useful prompt states the job, audience, evidence and requirements.

This makes it easier to judge the result rather than choosing the answer that sounds most confident.

Explain the added worked example · 2

Use this fictional source C: the paper modelling club meets Monday in Room 7, and participants bring paper. C gives no start time. Our task is a short information card for Grade 6 readers.

It must report day, time, place and what to bring, using only C. There is no need to supply names or private information.

Explain the added worked example · 3

Prompt P1: Using only source C, produce an information card for Grade 6 readers. Return exactly four labelled lines in this order: Day, Time, Place, Bring. Copy or faithfully restate each supported value.

For a missing value write “not stated”. Add no other details. Source C: the paper modelling club meets Monday in Room 7; bring paper.

Explain the added worked example · 4

For P1, an acceptable card has Day: Monday; Time: not stated; Place: Room 7; Bring: paper, each on its own line. The semicolons here separate lines for discussion.

A correct format with an invented 3 pm time still fails the evidence requirement. Accurate facts inside a long paragraph still fail the requested four-line format.

These are classroom response examples written for inspection, not measurements from a live AI system. You can test the instructions by asking a partner to follow them on paper.

That checks how clear the instructions are, but it does not prove that a model will always follow them.

Address these additional misconceptions

A tidy response is a correct response: Score facts and missing-value handling separately from layout.

A better prompt guarantees correct output: Inspect actual responses; even explicit requirements can be violated.

A conflict can be resolved by choosing the confident record: Without authority or priority, flag the unresolved field.

The best attempt represents every attempt: Keep all planned trials and report failures rather than selecting only a success.

W3 Handle disagreement without choosing a favourite

Workbook question · W3

C gives Room 7 and D gives Room 9 for the same club event, with no replacement or priority stated. Both agree on Monday and paper, and neither gives a time.

Day: Monday; Time: not stated; Place: conflicting information; Bring: paper. Neither source is given priority, so choosing one room from style or confidence would invent a resolution.

W4 Specify and test a new exhibit card

Workbook question · W4

Fictional record X says an exhibit is called Shadow Pairs and is in Hall 2; no opening time is given. Write a complete prompt for a Grade 6 card with exactly three labelled lines: Title, Location, Opening.

Limit facts to supplied records, define missing and conflicting values and prohibit added claims. Give two test inputs and expected outputs: original X, then X with an opening time of 10 am added.

Teacher reasoning · W4

A valid prompt names the Grade 6 card task, supplied records only, exactly three lines in Title/Location/Opening order, not stated for missing values, conflicting information for unresolved disagreements and no added details.

It includes X. Original X gives Title: Shadow Pairs; Location: Hall 2; Opening: not stated. Adding 10 am gives the same title and location with Opening: 10 am. Equivalent clear wording is acceptable.

W5 Preserve the comparison evidence

Workbook question · W5

A pupil tries P1 once and P2 five times, then compares the P1 response only with the best P2 response and declares P2 always reliable. Identify two problems and design a fairer small comparison.

State a conclusion the evidence could support.

Teacher reasoning · W5

Selecting only the best P2 output hides failures; unequal trial counts and an always-reliable claim also undermine the comparison.

Use the same cases, criteria and recorded model conditions, with the same planned number of runs for each version. Keep all outputs and report pass counts and failures.

The evidence can describe performance on these trials, not guarantee all future outputs.
