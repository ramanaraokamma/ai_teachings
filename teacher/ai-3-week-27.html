Concept to explain

Adversarial testing searches for predictable failure before users find it.

TermMeaning
red teamDeliberately test a system with challenging permitted cases to discover failures and improve safeguards.
adversarial inputAn input deliberately designed to expose a failure or make a system behave incorrectly.
prompt injectionText in an input or retrieved source that tries to redirect a system away from its authorised instructions.
mitigationA measure intended to reduce a specified risk, without necessarily removing it entirely.

Main misconceptions

The worked result establishes every future case: Adversarial testing must remain within authorised scope; a limited test set cannot certify all possible attacks.
