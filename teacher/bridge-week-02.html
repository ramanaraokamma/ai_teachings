Set the task and script workflow

A count and a shelf label can look similar while needing different operations. The integer 8 is a number; "08" is text that preserves a leading zero.

You can count eight objects, but adding two shelf labels is usually meaningless. This week you will examine values, trace changes to names and explain which representation a task needs.

Use the saved Python 3 script workflow from Week 1. Make a new file values.py, predict before running and keep actual output separately. Use fictional labels only.

Four useful types are int for whole numbers, float for floating-point numbers, str for text, and bool for True or False. A type describes a value, not whether its meaning is sensible for the task.

type(count) produces the type of the value bound to count. These print lines display <class 'int'> and <class 'str'>. The quotes in "08" mark text; they are not displayed by print(shelf).

True and False have capital initials and no quotes. "False" is text, not a Boolean.

Trace the saved 8 while count becomes 10

count = 8
saved = count
count = count + 2
print(count)
print(saved)

The outputs are 10 and 8 on separate lines. saved = count uses the value available at that moment.

It does not store a formula that keeps following count. count = count + 2 is valid assignment: read the old 8, calculate 10, then rebind count. It is not a claim that 8 equals 10.

Read the count/tag example

A number and its printed-looking text. A program stores a numeric badge count and a string that looks like that count.

Python 3: count=8; tag="8"; print(count+2); print(tag+"2").

Trace type-dependent operations

Values carry types, not merely appearances. The plus operator performs numeric addition for these integers and concatenation for these strings; the mixed operation is invalid here.

Diagnose misconceptions

Digits always mean a number: Quotes make a string, even when every character is a digit.

Changing one scalar name updates every earlier assignment: Trace the value bound at each assignment; no formula link is stored.

The right type guarantees valid data: A negative integer can be an invalid object count.

Lowercase false is Python’s Boolean false value: The literal is False; lowercase false is a name and is undefined in a fresh script.
