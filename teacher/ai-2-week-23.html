options = [{"name": "A", "fun": 4, "learning": 2, "minutes": 15},
           {"name": "B", "fun": 3, "learning": 5, "minutes": 25}]
for item in options:
    if item["minutes"] <= 20:
        score = 2 * item["fun"] + item["learning"]
        print(item["name"], score)

Explain inclusive eligibility and collect the changed weights

Only A is printed, with score 10. If B took 20 minutes it would qualify and have the higher score 11. The inclusive boundary matters.

Ratings and weights are invented for practice and require justification before use in a real decision.

Introduce the separate14-minute case

A fictional book-activity chooser has a 14-minute limit.

Score=2×interest+practice. A=(interest3,practice2,time14); B=(4,3,15); C=(2,5,12).

Require whole nonnegative feature values; time must be at most the limit. Highest score wins; tie by ID.

Trace its eligible scores and limits

A score combines preferences according to explicitly chosen weights; it does not erase hard constraints.

Computing a high score for an excluded item can be useful in an audit, but it must not allow that item back into the candidate set. Store both eligibility reasons and score components for explanations.

Toy interest scores are supplied inputs, not measured enjoyment or a universal definition of a good activity.

Change the interest weight without changing eligibility

Change: Change interest weight from 2 to 3, keeping time limit 14.

Prediction: A scores 11; C also scores 11; tie-by-ID chooses A.

Reason: B remains too long; changing preferences changes only ranking of A and C.

Run the complete audit, tie and empty-set branch

options = [{"id": "A", "interest": 3, "practice": 2, "minutes": 14},
           {"id": "B", "interest": 4, "practice": 3, "minutes": 15},
           {"id": "C", "interest": 2, "practice": 5, "minutes": 12}]
limit = 14
for interest_weight in [2, 3]:
    scores = {}
    review = []
    for item in options:
        values = [item.get(key) for key in ["interest", "practice", "minutes"]]
        if not all(type(value) is int and value >= 0 for value in values):
            review.append((item["id"], "missing or invalid input"))
        elif item["minutes"] > limit:
            review.append((item["id"], "exceeds time limit"))
        else:
            scores[item["id"]] = interest_weight * item["interest"] + item["practice"]
    print("weight", interest_weight, "scores", scores, "review", review)
    if not scores:
        print("No eligible option")
    else:
        highest = max(scores.values())
        tied = sorted(name for name in scores if scores[name] == highest)
        print("top", tied, "chosen", tied[0])

W1 score key

An eligible activity has fun 2 and learning 4. Use 2 * fun + learning.

Score 8.

Substitute each rating into its named role: 2 * fun + learning = 2 * 2 + 4 = 4 + 4 = 8. Eligibility is supplied in this task, so this calculation ranks an already permitted option.

The score is a result of the chosen preference rule, not a measured educational benefit.

W2 boundary key

Which durations 19, 20, 21 qualify under at most 20?

19 and 20 qualify; 21 does not.

At most 20 means minutes <= 20. The value 19 is below the limit and 20 is exactly at it, so both qualify. The value 21 is above it and is excluded.

An answer that rejects 20 has changed the inclusive requirement into a strict one.

Offer the eligible item with score 9. The constraint is applied before ranking.
