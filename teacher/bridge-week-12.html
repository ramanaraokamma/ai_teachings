Read independent expectations and assertion semantics

A function can pass one example by coincidence. Start with a written rule, calculate expected results independently, and include ordinary, zero and boundary cases.

We will test a subtraction function under the contract 0 <= used <= capacity.

Each parenthesized group is a tuple, an ordered group of values. The loop unpacks each group into three names. Equality compares the actual result to the independently calculated expected result.

The worked script prints True three times. An assert actual == expected could instead stop at the first mismatch with AssertionError.

Supply the complete W2 candidate and cases

def remaining(capacity, used):
    return 4  # intentional candidate defect: ignores both arguments

cases = [(6, 2, 4), (6, 6, 0), (6, 0, 6)]
for capacity, used, expected in cases:
    actual = remaining(capacity, used)
    print(actual, expected, actual == expected)

Read the pictured tiny contract

Use a test that catches the boundary bug. A function should classify an integer as tiny exactly when it is less than three.

Python 3 intended function: return x<3. Test cases: (2,True),(3,False),(4,False). Candidate bug: return x<=3.

The complete tiny program below uses assertions in normal test execution. Correct <3 passes 2,3,4 and prints the completion line. Changing only < to <= passes the first assertion, fails at 3 with AssertionError and never runs the assertion for 4 or final print. The graphic compares expression results one at a time; it is not a trace claiming later assertions executed after failure.

The completion message is a literal string, not an automatic count of executed checks. If removing a test, relabel it for the two retained checks. These are local test checks, not a production input-validation mechanism.

Trace the strict-boundary defect

A revealing test distinguishes a correct implementation from a plausible mistake. Checking only values far from the boundary would miss this inclusive-versus-strict bug.

def tiny(x):
    return x < 3

assert tiny(2) is True
assert tiny(3) is False
assert tiny(4) is False
print("three checks passed")
