The program uses fictional values and the Python standard library; it performs no external operations.

from itertools import combinations

def sample_means(population, size):
    if type(size) is not int or not 1 <= size <= len(population):
        raise ValueError('sample size')
    return [sum((population[i] for i in indices)) / size for indices in combinations(range(len(population)), size)]

print(sample_means([1, 1, 3, 3], 2))

A pictorial worked case: Sampling variability

Two small samples can differ. A fixed classifier is scored on two distinct four-case samples from a declared collection.

The facts we will use

Sample A has 3 correct of 4; sample B has 2 correct of 4. The model and rubric are unchanged.

Why this result follows

Sampling variability means a statistic can vary because different units were observed. Do not automatically attribute every rate change to a model improvement or deterioration.

What this example does not establish

These two samples do not supply a probability model or confidence interval; none is invented.

Prediction: The counts should agree unless some condition, data or scoring changed.
