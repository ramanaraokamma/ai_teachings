Read the supplied validator

rows = [{"activity": "Reading", "minutes": 12},
        {"activity": "Sorting", "minutes": 0}]
for row in rows:
    valid = (type(row["activity"]) is str
             and len(row["activity"]) > 0
             and type(row["minutes"]) is int
             and 0 <= row["minutes"] <= 60)
    print(valid)

Explain exact types and boundary checks

The worked script prints True twice. type(value) is int checks the exact type here and avoids accepting a Boolean as a count. The chained comparison checks both boundaries. The example assumes both keys exist; this week’s paper audit identifies missing fields without treating this script as a complete missing-field validator. A zero duration is allowed by this written schema.

    Introduce the separate book contract

    A fictional approved book catalogue has three fields per row.

    Schema: id is nonempty text; pages is an integer 1–300; illustrated is Boolean True or False.

    Rows A={id:"B7",pages:90,illustrated:True}; B={id:"B8",pages:"90",illustrated:False}; C={id:"",pages:80,illustrated:True}.

    Trace the three catalogue records

    A schema makes row meanings and expected types explicit. The string "90" looks like a number when printed but does not meet this strict integer schema. A repair can be authorised later, but must not be assumed silently.

    Missing or empty identifiers also prevent tracing an item back to its source.

    Separate validity from factual accuracy

    Schema validity does not confirm that the book really has 90 pages or that its metadata is accurate.

    Reason: Its id is nonempty and illustrated is Boolean; the page-type defect is removed.

    W1 duration schema key

    List the required fields, types and duration boundaries for the worked table.

    activity: nonempty text; minutes: integer from 0 to 60 inclusive.

    Check both fields. activity must exist as nonempty text. minutes must be an exact integer and satisfy 0 <= minutes <= 60. Inclusive means equality is accepted at both ends.

    Structure, type and range are separate checks; passing them does not prove the duration was measured accurately.

    W2 boundaries key

    Classify minutes values 0, 60, -1 and 61 under this schema.

    0 and 60 pass; -1 and 61 fail.

    Apply the inclusive range to each integer. Both 0 and 60 are on allowed boundaries. -1 is below the minimum and 61 is above the maximum. Require the reason for each rejection, not only pass/fail labels.

    W3 unit conversion key

    A source says 180 seconds but the row says minutes: 180. Give a documented correction.

    Divide by 60 to record 3 minutes and retain the source value and conversion note.

    W5 validity limit key

    A row says Reading, 12 and passes. Does that establish the session really lasted 12 minutes?

    No. The value has a permitted structure but still needs trustworthy collection evidence.
