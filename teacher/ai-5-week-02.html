Teacher guide · 2 of 6

Explain and model the mechanism

A small model can combine several measurements into one score. Let x = [4, 2] contain fictional width and height measurements in cm. Set weights w = [2, -1]. Multiply matching positions, then add: s = (2 times 4) + (-1 times 2) = 6. The letter x names the input vector.

We call this calculation a dot product, written w dot x. The vectors must have the same number of components. Each weight belongs to one named feature. These hand-selected weights demonstrate a computation; no training has happened. The result 6 is a score, not a probability or a claim that this parcel is safe.

The coefficients carry score-per-cm units in this example, making both contributions compatible score units. A weighted sum needs a consistent definition of units.

Keep w = [2, -1] fixed. For A = [4, 2], the score is 6. For B = [2, 4], it is 4 - 4 = 0. For C = [3, 3], it is 6 - 3 = 3. Swapping input positions without swapping their matching weights changes the computation. A zero score can come from cancellation, even when neither input is zero.

The length check matters: Python zip alone stops at the shorter list and could silently omit a feature. The function assumes numeric inputs already validated under the schema. First predict the three printed values on paper, then compare.

A pictorial worked case: Dot products and weighted sums

Draw each input’s contribution to a toy weighted brightness score.

The facts we will use

Inputs [2, 5]; weights [3,-1]; no bias. Score is 2×3+5×(-1).

All inputs and outcomes in this worked example are invented classroom data; no real model run is claimed.

Why this result follows

A weight controls how strongly an input contributes to the score. The left connection adds three times its measurement; the negative right connection subtracts its measurement. Calculate each contribution before adding them. This dot product is a signed score; it becomes a probability only if a separate, justified transformation and interpretation are supplied.

What this example does not establish

These declared weights are hand-chosen toy parameters; no network training or calibrated probability is claimed.

Change one thing in the pictured case

Change: Increase only the right input from 5 to6.

Prediction: The score becomes6-6=0.

Reason: The right weight is-1, so adding1 to that input lowers the score by1.

Ask while showing the picture

Cover the result. Ask learners to name the inputs and predict the next step. Uncover one step, connect the icon to the actual procedure, and explain its evidence. Then change the supplied condition and compare. The picture is a representation; it does not document execution of a real AI model.

Individual reasoning check

Expected correction: The operation is 2 times 4 plus -1 times 2, not (2 - 1) times (4 + 2). That shortcut happens to match for some inputs but is not the rule.

Teacher guide · 4 of 6

Run the investigation and diagnose misconceptions

Multiply the sums instead: The operation is 2 times 4 plus -1 times 2, not (2 - 1) times (4 + 2). That shortcut happens to match for some inputs but is not the rule.

Negative means unimportant: A negative coefficient changes direction. Units, data and the rest of the model affect interpretation.

The weights have been learned: These values were supplied. Training would require data, an objective and a fitting procedure.

Use Section 9 for the evidence ledger. Add a boundary or missing-input case and record the expected response before checking. More successful repeats of one case do not establish wider coverage.

Assess and explain the answers

Guided and exit questions

Guided: [4, 3] gives 8 and -3, total 5, down 1 from 6 because height rose by 1 with coefficient -1. Exit: the score has no supplied probability mapping, fitted probability model or calibration evidence. Multiplying it by ten does not create a supported probability.

W1 Calculate contributions

For w = [2, -1] and x = [3, 5], write both contributions and their sum.

Teacher explanation: Contributions are 6 and -5, so the score is 1.

W2 Explain cancellation

For w = [2, -1] and x = [2, 4], explain why score zero does not mean the input contains no information.

Teacher explanation: Contributions 4 and -4 cancel. The input still contains width 2 and height 4; zero is the combined score.

W3 Preserve a unit change

Width stays in cm and height changes to mm. For the worked parcel [4 cm, 20 mm], give the revised weights and score.

Teacher explanation: Use [2, -0.1]. Contributions 8 and -2 give score 6, preserving the original measurement meaning.

W4 Compute a new dot product independently

Use x = [3, 1, 2] and w = [-2, 4, 0.5]. Give each contribution and the total. Increase only the second component from 1 to 2 and compute the new total. Explain why a two-weight list is invalid for this input.

Teacher explanation: Contributions -6, 4, 1 give -1. With second component 2, contributions -6, 8, 1 give 3, a rise of 4. Three input components need three matching weights; silently dropping the final component changes the computation.

W5 Find lost information

Verify that [4, 2] and [5, 4] both score 6 with w = [2, -1]. Can a later step receiving only this score distinguish those two records?

Teacher explanation: The scores are 8 - 2 = 6 and 10 - 4 = 6. A deterministic later step receiving only 6 receives identical information and cannot distinguish them.

Independent assessment and fresh retry

W4 requires contributions -6, 4, 1 and total -1, changed total 3 and a dimension check. Fresh retry: w = [1, -3, 2], x = [2, 1, 4] gives 2 - 3 + 8 = 7. If only the third input falls to 3, the score is 5. Ask for the two-point decrease explanation.

Feedback that the learner uses

Name the earliest unsupported step and give one action to repair it. Have the learner make that repair now and explain why. Then assess the relevant skill on a fresh, fully specified case.
