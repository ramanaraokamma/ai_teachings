Before class, solve the supported practice: Classify minutes values 0, 60, -1 and 61 under this schema.

Reasoned practice answer: 0 and 60 pass; -1 and 61 fail.

Check every learner before discussion: Use the worked case for Rows columns and schemas. Proposed explanation: “A successful run proves the conclusion”. Decide whether this explanation is supported. Point to the step or supplied fact that decides; explain your repair if needed.

Misconception repair: A row can satisfy every schema rule and still be a wrong observation. Schema validation checks our stated structure and constraints, not whether someone measured honestly or selected a representative sample.

Support: read the exact case aloud, enlarge the labelled picture, supply input cards and model only the first deciding step. Accept a spoken explanation or drawing; retain the reasoning goal.

Extension: S changes from 0 to None. Require a prediction and a reason before comparing. Expected result: Mean becomes (2+6)/2=4 cm with 2/4 measured. Reason: Removing a measured zero changes both the denominator and the coverage.

Independent assessment: withhold the reserved answer until the learner has attempted the new case. Record support separately from correctness.
