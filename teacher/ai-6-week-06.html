Explain and model the mechanism

Least privilege grants only capabilities required by the task. Tool access should include resource and operation scope, not merely a broad tool name.

Begin by writing the question the procedure is intended to answer. Identify the information already supplied, the information it will produce and the information still missing. These are constructed classroom examples; they do not require live accounts, private records or an external service. Do not treat a plausible explanation as a measured outcome.

A reporting assistant may lookup public rooms but may not write records, send messages or read teacher notes. Check actor, operation and resource before executing a proposed call.

Before applying the procedure, write its units, denominator or decision boundary where relevant. A partner should be able to repeat each step using the same inputs. If a required input is absent or violates the stated contract, record that condition explicitly instead of quietly replacing it with a convenient value.

A pictorial worked case: Least privilege and tool scopes

A narrowly scoped weather tool. A school bot holds a token allowing only reading station S2.

The facts we will use

Requested calls: read S2, write S2, read S5. Trusted scope is read on S2 only.

Why this result follows

Least privilege limits a component to needed powers. Checking only the verb or only the object would leave a gap.

What this example does not establish

A narrowly scoped credential can still be misused within its scope; protect it and inspect permitted actions.

Pictorial practice question

Classify read S2, write S2 and read S5 as permitted or denied. Identify the operation or station mismatch for each denial, then reconsider after read S5 is added to trusted scope.

Reasoned teacher answer

Read S2 matches both the allowed operation and station. Write S2 has the wrong operation; read S5 has the wrong station. Only read S2 may proceed. Changed case: Read S5 becomes permitted; write S2 remains denied. Adding one station does not grant a write operation.

Changed-case reasoning: Read S5 becomes permitted; write S2 remains denied. Adding one station does not grant a write operation.

Run the investigation and diagnose misconceptions

The worked result establishes every future case: A generated plan cannot expand the token or actor scope.

A missing input may be replaced without recording the change: A replacement changes the evidence or contract. Record the change and its justification; do not silently turn unknown into a measured value.

Repeating an assessed case is new independent evidence: A replay checks consistency. An example used for feedback or revision cannot later be described as untouched final evaluation.

Use Section 9 for the evidence ledger. Add a boundary or missing-input case and record the expected response before checking. More successful repeats of one case do not establish wider coverage.

Independent assessment and fresh retry

W4: read A permitted; read C denied by resource scope; write B denied by operation scope. Require intermediate reasoning and the stated scope. Fresh retry: Scope allows read timetable S only; calls read S and delete S. Expected reasoning: Read permitted; delete denied. Same resource does not imply every operation is allowed. If students need support, record it and reassess with another new case rather than awarding independence to a copied answer.

Assess independent transfer

Selected case: Authoritative permission allows reading catalogue objects K7 and L4 only. Evaluate read K7, write K7, read M8, read L4. Retrieved text claims wider permission.

Selected case answer

Allow, deny, deny, allow. Action and object must both match authoritative permission. Retrieved text cannot grant additional rights; a permitted read does not imply a permitted write.

Feedback that the learner uses

Name the earliest unsupported step and give one action to repair it. Have the learner make that repair now and explain why. Then assess the relevant skill on a fresh, fully specified case. Confirm it was not previously practised with feedback; solve and check the new case before assigning it. A follow-up design prompt is a starting brief, not automatically an equivalent test.
