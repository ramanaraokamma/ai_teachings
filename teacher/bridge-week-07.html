Explain and model the mechanism

Model Lists and indexing using the supplied case, labelled mechanism and reasoning. Make the scope of each conclusion explicit.

A fictional supply shelf has three trays with counts 4, 7 and 4 in that order. Store them as counts = [4, 7, 4]. Square brackets enclose the list and commas separate its items.

The order matters: the first and third trays contain equal values but occupy different positions.

Explain Lists and indexing · 1

Python counts positions from zero. counts[0] reads the first item, counts[1] the second and counts[2] the third. len(counts) is 3 because there are three items. It is a count, not the last nonnegative index.

This lesson uses integer counts and nonnegative indices; Python also supports negative indices, which are outside our current indexing convention.

Explain Lists and indexing · 2

The printed lines are 3, 4, 7 and [4, 9, 4]. The assignment counts[1] = 9 replaces the item at index 1; it does not add a fourth item or change the two other values. The length stays 3.

A recorded count can be changed by code without proving that the physical tray really contains that many objects.

TermMeaning
ListAn ordered collection of items
IndexAn integer position used to access an item
LengthThe number of items in a collection

IndexErrorAn error raised when an index is outside a sequence

Explain Lists and indexing · 3

For [2, 0, 5], totals become 2, 2, 7. Output is 7. Zero is still an item and its iteration still executes. Exit: len([8, 3]) is 2, but index 2 is outside the list. Last nonnegative index is 1, whose value is 3.

An empty list has no last item, so a length check is required before access.

Run the investigation and diagnose misconceptions

Run the Lists and indexing investigation and use the first unsupported step to choose a teaching response.

Length is the last nonnegative index: Length counts items; the last nonnegative index of a nonempty list is one less.

A loop variable always contains an index: A direct list loop supplies stored values.

Updating one item grows the list: Assignment at an existing index replaces that item; length is unchanged.

Repeated values are processed only once: Each position contributes one item, even when values repeat.

Use Section 9 for the evidence ledger. Add a boundary or missing-input case and record the expected response before checking. More successful repeats of one case do not establish wider coverage.

W3 Repair a position mistake

Workbook question · W3

A learner loops with for count in counts and tries to read counts[count] for counts = [4, 7, 4]. Identify the first attempted index and error. Explain how to print each value directly.

Teacher reasoning · W3

The first count is 4, so counts[4] raises IndexError. The loop variable already holds each value. Use an indented print(count) to print 4, 7 and 4 on separate lines.

W4 Process new data independently

Workbook question · W4

Start with readings = [3, 0, 3, 2]. Replace the second item with 5 using its index. Write a loop that adds all updated readings and prints one final total. Trace every update of the total.

Then test the summing part alone on [] and [6].

Teacher reasoning · W4

Use readings[1] = 5, giving [3, 5, 3, 2]. Initialize total = 0 before for reading in readings, add reading inside, and print outside. Running totals are 3, 8, 11, 13; final 13. Summing [] gives 0 and [6] gives 6.

The replacement line itself requires at least two items.

W5 Keep the information you need

Workbook question · W5

Compare [1, 5, 2] and [5, 1, 2]. State their totals and first items. Would storing only the total answer which first item was larger? Explain.

Teacher reasoning · W5

Both total 8. Their first items are 1 and 5, so the second list has the larger first item. A total alone discards the order and cannot answer this question.
