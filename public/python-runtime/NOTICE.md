# Vendored classroom Python runtime

Pyodide 314.0.7 (MPL-2.0), downloaded from the official npm package.
Official project: https://github.com/pyodide/pyodide
Documentation: https://pyodide.org/en/stable/usage/webworker.html
The MPL license is included in LICENSE. Python standard-library license notices are retained inside python_stdlib.zip.
Only the core runtime is included. The classroom labs use standard-library examples; no package installation is performed by the lab worker.
